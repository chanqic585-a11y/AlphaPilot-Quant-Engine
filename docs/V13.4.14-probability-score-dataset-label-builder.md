# AlphaPilot V13.4.14 - Probability Score Dataset and Label Builder

V13.4.14 adds the probability score dataset and forward label builder for the
Dynamic Regime strategy mainline.

中文说明：

```text
V13.4.14 构建概率评分样本、未来 TP/SL 标签、MFE/MAE 和条件概率表。
本版本不是策略交易版，不运行回测，不进入 Dry-run，不实盘。
```

## Inputs

```text
reports/v13_4_13_dynamic_universe_snapshots.json
user_data/data/okx/futures/*-1h-futures.feather
```

The universe snapshots determine which pairs were eligible on each historical
date. The local OHLCV files provide point-in-time candles and future windows for
labels.

## Added Modules

```text
alphapilot/probability/probability_schema.py
alphapilot/probability/condition_buckets.py
alphapilot/probability/label_builder.py
alphapilot/probability/probability_score_table.py
alphapilot/probability/build_probability_dataset.py
scripts/build_probability_dataset.ps1
```

## Run

```powershell
python -m alphapilot.probability.build_probability_dataset
```

or:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_probability_dataset.ps1
```

reports/v13_4_14_probability_score_table.json

## Result

```text
snapshotCount: 155
sampleCount: 1540
labeledSampleCount: 1540
insufficientDataCount: 10
windows: 8, 12, 24
primaryWindow: 12
TP: +5%
SL: -2.5%
```

The score table currently contains many fine-grained bucket combinations, so
most rows are `insufficient_sample` and remain `observe_only`. This is expected
for the first dataset version and prevents over-claiming from small samples.

## Safety Boundary

V13.4.14 reads local public OHLCV and historical universe snapshots only. It
does not implement strategy entries, run Freqtrade backtests, enter Dry-run,
use API keys, call Trade API or Withdraw API, read accounts, read positions,
create orders, or auto trade.
