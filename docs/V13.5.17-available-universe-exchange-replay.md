# AlphaPilot V13.5.17 - Available-Universe Exchange Replay

V13.5.17 expands the exchange-aware replay from BTC/ETH/SOL to every locally available public 4h futures file per exchange.

It uses only files already present under:

```text
user_data/data/{exchange}/futures
```

This version does not download data, tune parameters, run Dry-run, connect to private exchange endpoints, create orders, or approve live trading.

## Active Pool

```text
4h:alpha_short_exhaustion_pressure_watch:sl0.06:h24
```

The active pool remains fixed. V13.5.17 is a sample-size and exchange-balance diagnostic, not a parameter search.

## Commands

Preview:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_17_available_universe_exchange_replay.ps1
```

Generate reports:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_17_available_universe_exchange_replay.ps1 -Run
```

Outputs:

```text
reports/v13_5_17_available_universe_exchange_replay_report.json
reports/v13_5_17_available_universe_exchange_replay_summary.md
reports/v13_5_17_available_universe_exchange_signal_log.json
```

## Decision Rules

The report separately checks:

- sampleAdequate: enough active-pool events and enough unique pairs
- exchangeBalanceAdequate: enough non-OKX events and enough exchanges
- readyForExchangeDryRunReview: always false in this version

If exchange balance is not adequate, the next action is to expand non-OKX public data in smaller resumable batches, not to overfit the active pool.

## Safety Boundary

- No Trade API.
- No Withdraw API.
- No API key storage.
- No real account reads.
- No real position reads.
- No order creation.
- No automatic trading.
