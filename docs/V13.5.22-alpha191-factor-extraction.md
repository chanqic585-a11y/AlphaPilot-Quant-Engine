# AlphaPilot V13.5.22 - Alpha191 Factor Extraction

V13.5.22 extracts a copyright-safe research catalog from the user-provided
local PDF `Alpha191因子公式小白学习手册.pdf`.

This version does not copy full formulas or long source explanations. It stores
only factor IDs, categories, operator tags, required fields, short
implementation notes, source metadata, and citation text.

## Purpose

Alpha191 is useful as a factor idea library, not as a direct trading command.
V13.5.22 turns the PDF into an AlphaPilot research catalog so later versions can
select a small crypto-safe implementation subset and test it against the
existing V13.5 local paper gates.

## Inputs

```text
tmp/pdfs/alpha191_extracted_text.txt
```

The text file is a temporary UTF-8 extraction from the user-provided PDF. The
raw PDF and raw extracted text are not committed to the repository.

## Commands

Preview:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_22_alpha191_factor_extraction.ps1
```

Generate reports:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_22_alpha191_factor_extraction.ps1 -Run
```

Outputs:

```text
reports/v13_5_22_alpha191_factor_extraction_report.json
reports/v13_5_22_alpha191_factor_extraction_summary.md
reports/v13_5_22_alpha191_factor_candidate_catalog.json
```

Known formula extraction issues from the source note are marked for manual
review instead of being silently treated as clean implementation candidates.

## Copyright Boundary

Stored:

- source metadata
- short source summary
- citation
- factor ID
- category
- operator tags
- required fields
- short implementation notes

Not stored:

- complete formulas
- long source explanations
- raw PDF text
- copied pages

## Safety Boundary

V13.5.22 does not:

- change strategy rules
- run a backtest
- change local paper trading
- use API keys
- call Trade API
- call Withdraw API
- read real accounts
- read real positions
- create orders
- auto trade
- approve exchange Dry-run
- approve live trading

This is a factor research metadata step only.
