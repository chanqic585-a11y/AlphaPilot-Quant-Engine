# AlphaPilot V13.7.1 - Strategy Runtime Data Contract

V13.7.1 adds a local, read-only runtime data contract for the desktop and mobile consoles.

It standardizes three files:

```text
reports/runtime_status.json
reports/signal_tape.json
reports/paper_observation_ledger.json
```

These files are generated from existing local research and local paper replay reports. They do not run a strategy, download data, call an exchange, use API keys, read accounts, read positions, create orders, run Dry-run, or auto trade.

## Files

`runtime_status.json` summarizes the active research strategy, runtime health, signal count, paper observation count, and safety boundary.

`signal_tape.json` publishes a capped list of historical research signal records for console display. Each record is marked as historical observation only.

`paper_observation_ledger.json` publishes a capped list of local paper replay observations and a summary of simulated historical metrics.

## Command

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_runtime_contract.ps1
```

## Safety Boundary

- Local file bridge only.
- No API key usage.
- No Trade API.
- No Withdraw API.
- No real account reads.
- No real position reads.
- No order creation.
- No exchange Dry-run approval.
- No live trading approval.
- No automatic trading.

## Console Integration

The desktop console and mobile app should read these files through the Control Console API. They are display and monitoring inputs only, not execution commands.
