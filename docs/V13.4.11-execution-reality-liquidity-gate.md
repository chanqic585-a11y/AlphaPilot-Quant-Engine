# AlphaPilot V13.4.11 - Execution Reality and Liquidity Gate

V13.4.11 adds the execution reality test layer before any future Dry-run
candidate review. It is a design and reporting version only.

中文说明：

```text
V13.4.11 是执行真实性测试与流动性闸门设计版。
它不调参、不跑回测、不进入 Dry-run、不实盘、不创建真实订单。
```

## Why This Version Exists

V13.4.10 confirmed that the V13.4.8 Trend Pullback smoke result did not
generalize to the wider V13.4.9 Top30 validation sample. The failure showed that
strategy research needs a stronger gate around liquidity, slippage, order
impact, execution data, and shadow trading before any candidate can move toward
Dry-run review.

## Added Modules

```text
alphapilot/execution_reality/liquidity_gate.py
alphapilot/execution_reality/slippage_model.py
alphapilot/execution_reality/order_impact.py
alphapilot/execution_reality/shadow_trading_schema.py
alphapilot/execution_reality/live_feasibility_score.py
```

These modules are research utilities. They do not connect to exchange private
APIs, do not read account data, and do not create orders.

## Proposal Integration

`TradeProposal` now supports optional execution reality context fields:

```text
liquidity_context
execution_reality_context
shadow_trading_context
live_feasibility_score
```

The fields are optional so old reports and proposal objects remain compatible.

## Risk Gate Integration

Dry-run candidate review now requires these checks:

```text
liquidity_gate_result
execution_reality_result
shadow_trading_result
```

If any of these are missing, the risk gate returns:

```text
rejected_before_dry_run_candidate
```

This is a research-blocking decision, not a trading action.

## Reports

Generate the report:

```powershell
python -m alphapilot.reports.generate_execution_reality_design_report
```

Outputs:

```text
reports/v13_4_11_execution_reality_design_report.json
reports/v13_4_11_execution_reality_summary.md
```

Expected decisions:

```text
dryRunApproved = false
liveTradingApproved = false
nextStepRecommendation = V13.4.12 - Shadow Trading Skeleton
```

## Safety Boundary

V13.4.11 does not add:

- real API keys
- Trade API
- Withdraw API
- account reads
- position reads
- real order creation
- automatic trading
- Dry-run execution
