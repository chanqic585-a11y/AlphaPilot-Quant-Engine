# AlphaPilot V13.4.13 - Historical Dynamic Universe Builder

V13.4.13 implements the historical Dynamic Universe builder for the Dynamic
Regime strategy mainline.

中文说明：

```text
V13.4.13 实现历史动态币种池构建器。
它只读取本地公开历史 OHLCV，按历史日期生成当时可见的动态币种池快照。
本版本不写策略代码、不运行回测、不进入 Dry-run、不实盘。
```

## Goal

For any backtest date, the strategy must be able to ask:

```text
Which pairs would have been selected using only data visible before that date?
```

This prevents a common selection bias:

```text
using today's hot pairs to backtest the past
```

## Ranking Formula

```text
universeScore =
  0.35 * rankScore(quoteVolume24h)
+ 0.25 * rankScore(quoteVolume3d)
+ 0.15 * rankScore(absReturn24h)
+ 0.10 * rankScore(absReturn3d)
+ 0.10 * rankScore(volatility3d)
+ 0.05 * rankScore(volumeExpansion24h)
```

Liquidity and volume dominate the score so the universe does not become a
simple momentum hot list.

## Data Policy

If quote volume is missing from OHLCV, V13.4.13 estimates it as:

```text
quoteVolume = close * volume
```

The build report records pairs with estimated quote volume.

If a pair has missing files, insufficient history, high missing candle rate, or
zero volume, the pair is excluded for that snapshot instead of being filled with
fake values.

## Safety Boundary

V13.4.13 reads local public OHLCV only. It does not connect to exchange private
APIs, does not read accounts, does not read positions, does not create orders,
does not run backtests, and does not auto trade.
