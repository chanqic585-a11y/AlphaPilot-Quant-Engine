## Interpretation

The runtime path is valid: Freqtrade loads the strategy and produces a real
result. The zero-trade result comes from the strict V13.4.14 probability gate:
no matched bucket satisfies the current `research_candidate` thresholds in the
smoke context.

This is a research checkpoint, not a strategy approval. It does not approve
Dry-run or live trading.

## Runtime Fix

Docker only mounts `user_data` by default. V13.4.16 adds a read-only reports
mount:

```text
./reports:/freqtrade/reports:ro
```

This allows the strategy to read V13.4.13 and V13.4.14 research artifacts in
the container without exposing credentials or writable report state.

## Safety Boundary

V13.4.16 uses public historical data and local Freqtrade backtesting only. It
does not use real API keys, call Trade API or Withdraw API, read accounts, read
positions, create orders, enter Dry-run, or auto trade.
