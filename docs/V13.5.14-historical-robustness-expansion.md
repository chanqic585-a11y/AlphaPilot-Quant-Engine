# V13.5.14 Historical Robustness Expansion

V13.5.14 expands historical diagnostics for the current active V13.5.7 alpha overlay pool:

```text
4h:alpha_short_exhaustion_pressure_watch:sl0.06:h24
```

This version does not search for new thresholds and does not optimize parameters. It keeps the active pool fixed and asks a narrower question:

```text
Does the current active research strategy remain understandable across more historical slices, pairs, regimes, factor buckets, and cross-market public context?
```

## Scope

V13.5.14 adds:

- Historical time-split diagnostics.
- Year and quarter diagnostics.
- Pair, BTC regime, exit reason, volatility, volume, and liquidity quality buckets.
- Market-state diagnostics for bull, bear, sideways, BTC sharp drop, and alt-rotation contexts.
- Walk-forward review using chronological 60/20/20 fixed-parameter splits.
- Stress tests for additional fees, slippage, delay, and extreme loss gaps.
- Lightweight factor outcome separation as an auditable machine-learning research input.
- Alpha101-style factor availability summaries.
- Cross-market public context from the V13.5.11 Yahoo public chart cache.
- A versioned signal log for the fixed active pool.

powershell -ExecutionPolicy Bypass -File scripts\download_historical_robustness_data.ps1 -UseTop100 -Exchanges "okx,binance,bybit" -Timeframes "4h,1d" -Timerange "20200101-" -BatchSize 20 -Prepend

Run it:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\download_historical_robustness_data.ps1 -UseTop100 -Exchanges "okx,binance,bybit" -Timeframes "4h,1d" -Timerange "20200101-" -BatchSize 20 -Prepend -Run
```

The downloader is intentionally batched. Some symbols will be unavailable on some exchanges or historical periods. Missing data must be reported and must not be fabricated.

## Interpretation

Historical robustness can improve confidence in the research direction, but it does not replace forward validation. The active 4h strategy still needs closed post-selection forward samples before any exchange Dry-run review.

Cross-market factor research can help identify robust factor families, but A-share, Hong Kong, US ETF, and index data must not be directly converted into crypto trading commands without separate normalization, labeling, and validation.

V13.5.14 is not a live trading version.
