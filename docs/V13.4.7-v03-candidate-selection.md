# V13.4.7 V03 Candidate Selection

V13.4.7 selects the first V03 implementation direction after the V13.4.6
strategy direction review.

It does not implement strategy code, does not run a backtest, does not enter
Dry-run, and does not connect real trading permissions.

## Inputs

```text
reports/v13_4_6_strategy_direction_review.json
reports/v13_4_6_strategy_direction_summary.md
reports/v13_4_6_strategy_status_archive.json
```

## Selected Direction

```text
selectedDirection = V03A+D
selectedStrategyId = alpha_trend_pullback_1h_v01
selectedStrategyName = AlphaPilot Trend Pullback 1H V0.1
```

V03A supplies the trend pullback continuation structure. V03D supplies the 1h
primary timeframe to reduce 15m noise, trade frequency, and cost sensitivity.

## Why This Direction

- V0.1/V0.2 15m signals were too dense and cost-sensitive.
- Expanded validation showed fee and slippage drag overwhelms the current edge.
- Weak-trend rebound attempts failed structurally.
- Trend pullback continuation is a cleaner response than more 15m threshold edits.
- A 1h primary timeframe directly addresses over-trading and noise.

## Rejected Alternatives

### V03B Breakout Retest Confirmation

Second priority. The structure is attractive, but robust support/resistance,
breakout, and retest detection should not be rushed into the first V03
implementation.

### V03C High Score Signal Only

Future enhancement layer. A score model can improve selectivity later, but the
first V03 should establish a simpler structural baseline before weights are
introduced.

### V03D 1h Main Timeframe

Merged into the selected direction. It is a timeframe and noise-reduction
decision, not a complete standalone strategy.
