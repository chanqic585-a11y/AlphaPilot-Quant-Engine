# AlphaPilot V13.5.19 - Risk-Normalized Portfolio Replay

V13.5.19 evaluates the V13.5.18 historical signal log with fixed portfolio-level throttles in R-multiple space.

This version does not change entry logic. It does not change the 2R target. It does not tune strategy parameters.

## Input

```text
reports/v13_5_18_non_okx_expansion_signal_log.json
```

## Risk Unit

Each selected historical signal is treated as:

```text
1R risk unit
```

The replay evaluates totalR, maxDrawdownR, profit factor, reward/risk, exchange coverage, and consecutive losses.

## Policies

The fixed policy set includes:

- raw_all_signals
- pair_7d_cooldown
- pair_14d_cooldown
- exchange_24h_pair_7d
- exchange_24h_pair_14d
- global_24h_pair_14d
- loss_guard_pair_21d
- drawdown_guard_12r_pause_14d

These are portfolio throttles only. They are not optimized entry signals.


## Gate

The local paper refresh review gate requires:

- at least 100 selected trades
- at least 3 exchanges
- at least 10 pairs
- profit factor at least 1.2
- reward/risk at least 1.8
- max drawdown not above 30R
- max consecutive losses not above 8

Passing this gate is not exchange Dry-run approval.

## Safety Boundary

- No Trade API.
- No Withdraw API.
- No API key storage.
- No real account reads.
- No real position reads.
- No order creation.
- No automatic trading.
- No exchange Dry-run approval.
- No live-trading approval.
