# AlphaPilot V13.16.0 - Auditable Market Data Foundation

## Purpose

V13.16 establishes reproducible market-data evidence before any new FactorRun,
machine-learning model, strategy candidate, historical replay, local forward
observation, OKX Demo release, or Live candidate is allowed to advance.

The raw directory is immutable input:

```text
D:\Codex-Workspace\回测数据
```

Generated artifacts stay inside the Quant repository under ignored
`data/market/` paths. Reports and implementation code are version controlled.

## Data Flow

```text
read-only raw CSV/XLSX
  -> classified raw catalog
  -> duplicate and unsafe-file exclusion
  -> canonical UTC Parquet
  -> public-only OKX increments
  -> cross-fragment continuity verification
  -> immutable DataSnapshot manifest
  -> local evolution registry
```

The catalog explicitly classifies annual files superseded by `_ALL` files,
checkpoint CSV files, timestamped duplicate exports, unconfirmed candle tails,
unknown exchange provenance, and unverified 5-minute market type.

## Point-in-Time Rules

- `timestamp_ms` is preferred over text or Excel serial timestamps.
- Excel serial conversion is a fallback only.
- Unconfirmed tails are removed, never treated as completed bars.
- OHLC and non-negative-volume invariants are enforced.
- Duplicate timestamps are removed during canonicalization and rejected across
  composite fragments.
- Gaps are measured and reported; they are never filled with invented bars.
- A multi-asset snapshot cutoff is the earliest group end, not the latest end.
- The manifest records both the earliest history start and common start.

## Resume and Idempotency

Catalog hashes are checkpointed atomically every 25 newly hashed files in:

```text
data/market/checkpoints/catalog_hash_checkpoint.json
```

Creating `data/market/checkpoints/PAUSE_REQUESTED` asks the hashing loop to stop
at a safe boundary. Removing it and rerunning resumes from cached file size,
modification time, and SHA-256 values.

Each canonical smoke Parquet file has a metadata sidecar that binds the source
SHA-256, canonical SHA-256, and quality result. An unchanged source can reuse
that sidecar without reopening the full XLSX file. The seed command creates
missing sidecars for pre-existing canonical files and never changes raw input.

Public OKX collection finds the latest timestamp across both the unverified
local base and previously saved verified OKX increments. A repeated run should
report `up_to_date_or_unavailable` instead of creating overlapping files.

## Provenance Blocker

The historical local base does not contain an authoritative source manifest
with exchange, license, download time, and original checksums. Its schema is
consistent with an OKX-style export, but schema shape is not proof of origin.

Consequently:

- local-base exchange remains `unknown`;
- the composite source is marked mixed;
- formal promotion remains blocked;
- no missing provenance is inferred;
- V13.17 research may use this snapshot for engineering smoke work, but cannot
  claim formal production evidence until provenance policy is resolved.

## Safety Boundary

V13.16 uses local data and unauthenticated public OKX market endpoints only.
It does not use API keys, read private account state, read positions, call Trade
API or Withdraw API, create orders, create Demo/Live releases, or enable Live
execution. The future strategy contract keeps reward/risk at `>=2R`; this phase
does not create or promote a strategy.
