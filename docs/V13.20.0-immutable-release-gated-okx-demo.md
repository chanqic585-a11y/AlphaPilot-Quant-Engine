# AlphaPilot V13.20.0 - Immutable-Release-Gated OKX Demo

## Purpose

V13.20 connects the evidence registry to the existing isolated OKX Demo
execution lifecycle. It does not weaken promotion criteria to make an order
appear.

## Promotion Gate

An immutable DemoRelease requires all of the following:

- registered StrategyCandidate and training DataSnapshot;
- point-in-time and leakage checks;
- FDR, deflated-Sharpe, and PBO checks;
- at least three valid walk-forward folds;
- fixed locked-OOS, doubled-cost, drawdown, realized `>=2R`, and concentration
  thresholds;
- frequency-specific forward closed-sample and calendar-day coverage;
- public-market forward evidence only;
- frozen inputs and matching code/data/model checksums.

Failure writes a decision/report but no executable contract.

## Console Runtime

The Control Console verifies the contract hash and exact 1000 USDT envelope.
Automatic signals are created internally from the immutable release, confirmed
OKX public candles, spread, and public contract sizing metadata. HTTP payloads
cannot inject automatic signals or portfolio state.

Before a Demo order, the console performs private Demo-only balance and
position reads, restart reconciliation, risk and concurrency checks, checksum
validation, rolling PF/loss/slippage drift checks, and pause/kill-switch checks.
The existing lifecycle supplies idempotent `clOrdId`, attached protective
exits, partial-fill reconciliation, restart recovery, and fail-closed unknown
state handling.

## Current Result

There is no formal StrategyCandidate in the real registry. Therefore no
DemoRelease or console release contract exists, and OKX Demo automation remains
blocked before credentials, scanning, or order creation.

## Safety Boundary

- OKX Demo only after an immutable release;
- runtime credentials are process-only and redacted;
- no raw key in files, SQLite, reports, browser storage, or Git;
- no Withdraw endpoint;
- no Live order or automatic Live promotion;
- no externally injected automatic signal;
- no profitability claim.
