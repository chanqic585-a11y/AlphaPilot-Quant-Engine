# AlphaPilot V13.4.15 - Dynamic Regime Strategy V0.1 Implementation

V13.4.15 implements the first Freqtrade strategy file for the Dynamic Regime
mainline.

中文说明：

```text
V13.4.15 新增 AlphaPilotDynamicRegimeV01.py。
本版本只实现策略代码，不运行回测，不进入 Dry-run，不实盘。
```

## Added File

```text
user_data/strategies/AlphaPilotDynamicRegimeV01.py
```

## Strategy Identity

```text
strategyId: alpha_dynamic_regime_v01
timeframe: 1h
direction: long only
status: research_backtest_only
dryRunApproved: false
liveTradingApproved: false
```

## Implemented Modules

```text
Dynamic Universe Filter
Market Regime Router

MeanReversionModuleV01

RiskGate placeholder via strict entry blocking
```

## Inputs

```text
reports/v13_4_13_dynamic_universe_snapshots.json
reports/v13_4_14_probability_score_table.json
```

If the universe file is unavailable, the dynamic universe filter blocks entry.
If the probability table is unavailable or the matched bucket is insufficient,
the probability gate blocks entry.

## Audit Columns

The strategy writes audit columns with the `ap_dyn_audit_` prefix:

```text
ap_dyn_audit_in_dynamic_universe
ap_dyn_audit_regime
ap_dyn_audit_probability_score_pass
ap_dyn_audit_liquidity_gate_pass
ap_dyn_audit_trend_module_pass
ap_dyn_audit_mean_reversion_module_pass
ap_dyn_audit_final_entry
ap_dyn_audit_skip_reason
```

Additional columns include probability bucket, probability sample count, and
liquidity gate decision.

## Liquidity Fallback

V13.4.15 sets:

```text
allow_liquidity_gate_fallback_for_backtest = true
```

This is only a research fallback so V13.4.16 can run a smoke backtest path. It
is explicitly marked in audit columns and is not a real liquidity approval.

## Safety Boundary

V13.4.15 does not run backtests, enter Dry-run, use real API keys, call Trade
API or Withdraw API, read accounts, read positions, create orders, or auto
trade.
