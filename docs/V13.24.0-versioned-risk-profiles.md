# AlphaPilot V13.24.0 - Versioned Risk Profiles

V13.24 replaces scattered fixed execution limits with immutable, checksummed
`RiskProfile` versions shared by Local Forward, OKX Demo, Live Canary, and
future Live Standard environments.

## What changed

- Every profile has an id, version, environment, payload checksum, and fixed
  safety envelope.
- New values create a new record; existing versions are never overwritten.
- Activation and rollback are append-only audit events.
- Forward releases, Demo releases, and Live candidate packages bind the exact
  profile id and checksum used for their review.
- Portfolio controls cover strategy count, position count, symbol/direction/
  correlation exposure, daily loss, drawdown, Canary loss, cooldown, data
  freshness, and liquidity.
- The minimum target remains `reward/risk >= 2R`.

## Safety boundary

Activating a RiskProfile does not authorize Demo or Live orders. The routine UI
cannot raise the fixed `SafetyEnvelope`, raw credentials are never persisted,
Withdraw is absent, and V13.24 contains no Live exchange adapter.

Generate the baseline report with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_24_risk_profiles.ps1
```
