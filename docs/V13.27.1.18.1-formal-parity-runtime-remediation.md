# V13.27.1.18.1 Formal Parity Runtime Remediation

V18.1 is a correction campaign for the V18 pre-result implementation failure.
It does not modify S01 signals, portfolio policies, exits, gates, the core
universe, splits, costs, benchmarks, or statistical policies.

## Scope

- Route authoritative signal identity through `CandidateAdapter`.
- Keep the formal validation core candidate-neutral.
- Preserve every V18 preregistration, ledger, artifact, commit, and tag.
- Freeze correction code and preregistration remotely before authorization.
- Create a new metadata-only Future Locked OOS identity after remote freeze.
- Permit exactly one research-only formal run.
- Keep Locked OOS reads, formal evidence, releases, Demo ARM, and orders at zero.

## Stage Order

1. Run the full pre-result test and safety gate.
2. Commit and push correction implementation code.
3. Create and remotely freeze the new preregistration.
4. Generate pre-result evidence and push the freeze commit.
5. Tag the freeze commit as `v13.27.1.18.1` and push the tag.
6. Create Future Locked OOS metadata and the one-shot authorization.
7. Commit and push authorization metadata.
8. Run the V18.1 formal validation once.
9. Record the mechanical route and close the campaign.

The preparation entry point is:

```powershell
python -m alphapilot.scripts.prepare_v18_1_formal_parity_correction <stage>
```

Supported stages are `preregister`, `evidence`, and `authorize`. The formal run
uses `alphapilot.scripts.run_v18_1_formal_walk_forward` and refuses to start
unless the remote freeze and authorization gates both pass.

## Counting Semantics

- `formalRunClaimCount`: one-shot run declaration.
- `formalRunAttemptCount`: formal process actually started.
- `formalResultRunCount`: authoritative result artifacts were generated.
- `resultReadCount`: strategy performance results were read.
- `formalResultArtifactCount`: authoritative result artifact count.

The predecessor V18 implementation failure remains one operational attempt and
zero result-read statistical trials.
