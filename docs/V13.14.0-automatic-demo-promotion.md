# V13.14.0 Automatic Demo Promotion

V13.14.0 adds four evidence-bound modules to the Factor Evolution Research Kernel:

- `promotion/gate.py`: fixed OOS, cost, drawdown, concentration, Shadow and checksum gates.
- `promotion/demo_release.py`: immutable decisions and Demo-only releases with a 1000 USDT risk envelope.
- `promotion/drift_monitor.py`: data, execution, slippage, calibration, regime and checksum drift checks.
- `promotion/rollback.py`: pause-first Demo rollback decisions that never act on live trading.

The Control Console adapter exports only release identity, strategy rules, risk
limits and checksums. It rejects credential-like fields recursively.

Current readiness is evidence-driven: if no formal strategy candidate has
passed every hard gate, `DemoReleases` remains empty and the report is
`blocked`. Legacy reports and early local observations are not silently
promoted.

Safety boundary:

- OKX Demo only after an immutable release exists.
- 1000 USDT initial Demo equity; 250 USDT maximum order notional.
- No raw credential storage.
- No Withdraw API.
- No automatic Live release.
