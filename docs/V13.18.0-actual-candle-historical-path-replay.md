# AlphaPilot V13.18.0 - Actual-Candle Historical Path Replay

## Purpose

V13.18 replaces synthetic outcome plumbing with a deterministic event-time
engine that consumes actual canonical OHLCV paths. It validates execution and
Outcome Ledger mechanics without pretending an engine probe is a strategy.

## Replay Contract

```text
decision: completed candle timestamp
entry: next candle open with directional slippage
stop: 1R
target: 2R
same candle touches both: stop first
timeout: close after 12 bars
fee: charged on entry and exit notional
funding: applied only when point-in-time funding rows are available
MFE/MAE: measured over the observed entry-to-exit path
```

Signals are processed in event-time order. A new signal is skipped while the
same instrument has an open interval, or when the portfolio concurrency limit
is reached. Missing decision timestamps, incomplete future paths, and invalid
risk distances fail explicitly.

## Outcome Ledger

Registry migration 2 adds immutable `OutcomeLedger` rows. Each record binds:

- evidence class and source entity;
- DataSnapshot and optional StrategyCandidate;
- instrument, timeframe, direction, decision, entry, and exit time;
- full replay outcome payload and content hash;
- V13.18 code commit through the outcome payload and artifact manifest.

The complete replay artifact is written under ignored `data/market/replay/` as
Parquet plus a checksum manifest. Rerunning the same code/snapshot/probe is
idempotent.

## Current Probe Result

```text
probe signals: 338
closed actual candle paths: 338
skipped paths: 0
formal strategy replay count: 0
```

The alternating fixed-cadence probe exists only to exercise both directions
and the full engine path. Its return, win rate, and drawdown are not strategy
performance and cannot satisfy a promotion gate. A formal replay remains
blocked until a StrategyCandidate passes the V13.17 evidence gate.

## Legacy Evidence

The V13.5.3 precomputed-return sandbox is now classified as
`legacy_synthetic`. It remains available for historical UI and orchestration
review, but is excluded from formal model training, performance claims, and
promotion totals.

## Safety Boundary

V13.18 does not use credentials, exchange accounts, positions, private APIs,
Trade API, Withdraw API, Demo orders, real orders, or automatic trading.
