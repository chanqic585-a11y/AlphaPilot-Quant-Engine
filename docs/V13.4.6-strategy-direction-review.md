# V13.4.6 Strategy Direction Review

V13.4.6 is a strategy direction review and V03 redesign preparation version.

It reads local V13.4.1 through V13.4.5 reports, archives the current Volume
Rebound V0.1/V0.2 series as rejected for Dry-run, and defines V03 candidate
directions.

It does not modify strategy code, does not run a new backtest, does not enter
Dry-run, and does not connect real trading permissions.

```text

reports/v13_4_5_expanded_validation_summary.md
```

All required input reports are present in the V13.4.6 run.

## Decision

```text
strategyFamilyStatus = rejected_for_dry_run
dryRunApproved = false
```

The current Volume Rebound V0.1/V0.2 series must not enter Dry-run.

V02B, V02C, and V02E showed some relative improvement in earlier comparisons,
but expanded validation and slippage-adjusted metrics remain deeply negative.
V02D failed the earlier smoke comparison. V02A improved in smoke comparison but
was not part of the successful expanded validation set and is not approved.

## Required Conclusions

- Volume Rebound V0.1/V0.2 current series does not enter Dry-run.
- B/C/E are relative improvements only; they are not usable after expanded validation and slippage adjustment.
- The failure is not a single-parameter problem.
- Continuing small edits inside the same framework carries high overfitting risk.
- V03 must redesign entry quality, trade frequency, payoff structure, and risk controls.

## Safety Boundary

V13.4.6 is research-only. It does not use real API keys, does not call Trade API
or Withdraw API, does not read real accounts or positions, does not create real
orders, does not auto trade, and does not modify the AlphaPilot Mobile App.
