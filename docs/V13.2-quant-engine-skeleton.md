# V13.2 Quant Engine Skeleton

V13.2 creates the first AlphaPilot Quant Engine repository skeleton.

Scope:

- Freqtrade user_data structure.
- OKX USDT swap backtest and dry-run config templates.
- Fixed Top 30 universe.
- `AlphaPilotVolumeReboundV01` strategy placeholder.
- Proposal, workflow, lock, handbook, risk gate, audit ledger, and report schema skeletons.
- Safe PowerShell helper scripts.

Non-goals:

- No live trading.
- No real API Key storage.
- No Trade API or Withdraw API.
- No account or position reads.
- No real order creation.
- No automatic trading.
- No complete strategy optimization.
- No machine learning or news system.

V13.2 prepared V13.3 strategy backtesting work while keeping execution disabled by default.

backtest strategy. See:
