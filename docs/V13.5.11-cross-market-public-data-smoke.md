# V13.5.11 Cross-Market Public Data Smoke

V13.5.11 adds a public cross-market data smoke test so AlphaPilot can begin
building a larger research sample base beyond crypto.

The first smoke set covers:

```text
A-share stocks
Hong Kong stocks
US ETFs
equity indices
```

These samples are research-only. They are not trading signals, not crypto
execution commands, and not exchange orders.

## Default Symbols

```text
600519.SS  Kweichow Moutai
000001.SZ  Ping An Bank
0700.HK    Tencent
9988.HK    Alibaba HK
SPY        SPDR S&P 500 ETF
QQQ        Invesco QQQ ETF
^HSI       Hang Seng Index
^GSPC      S&P 500 Index
```

## Run

Preview:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_11_cross_market_data_smoke.ps1
```

Generate reports:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_11_cross_market_data_smoke.ps1 -Run
```

Custom symbols:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_11_cross_market_data_smoke.ps1 -Run -Symbols "600519.SS,0700.HK,SPY,^GSPC"
```

## Data Source

V13.5.11 uses the Yahoo Finance public chart endpoint for smoke testing.

```text
https://query1.finance.yahoo.com/v8/finance/chart
```

This first version stores only aggregate quality reports in Git. Before any
production redistribution or large-scale dataset publication, data-source terms
must be reviewed separately.

## Research Use

Cross-market data can help with:

```text
market regime analogs
volatility references
liquidity context
factor robustness tests
macro risk context
```

It must remain explicitly labeled by market and asset type. It must not be
merged into crypto strategy execution without separate normalization,
validation, and review.

## Safety Boundary

V13.5.11 does not add:

```text
Trade API
Withdraw API
API key storage
broker credentials
real account reads
real position reads
real order creation
automatic trading
```
