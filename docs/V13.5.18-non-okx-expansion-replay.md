# AlphaPilot V13.5.18 - Non-OKX Expansion Replay

V13.5.18 records a practical public-data expansion step:

```text
Binance + Bybit
Top20 research subset
4h futures
2020-to-present
batch size 5
prepend enabled
```

The version then reruns the fixed active-pool available-universe replay.

## Active Pool

```text
4h:alpha_short_exhaustion_pressure_watch:sl0.06:h24
```

No parameters are changed.

## Commands

The data expansion command used public data only:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\download_historical_robustness_data.ps1 -Pairs "<Top20 research subset>" -Exchanges "binance,bybit" -Timeframes "4h" -Timerange "20200101-" -BatchSize 5 -Prepend -Run
```

Replay report preview:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_18_non_okx_expansion_replay.ps1
```

Generate report:


## Purpose

V13.5.17 showed that sample size improved, but exchange balance was weak. V13.5.18 tests whether adding more Binance and Bybit public data improves that balance without tuning the active pool.

If exchange balance remains weak or drawdown remains too high, the correct next step is review and risk control, not live execution.
