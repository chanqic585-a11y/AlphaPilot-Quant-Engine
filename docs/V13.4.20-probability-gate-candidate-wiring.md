# AlphaPilot V13.4.20 Probability Gate Candidate Wiring

V13.4.20 converts the V13.4.19 coarse probability bucket research output into
research-only probability gate candidate configs.

This version does not run a backtest, does not modify
`AlphaPilotDynamicRegimeV01.py`, does not modify the default probability gate,
does not approve Dry-run, and does not add any live trading capability.

## Inputs

- `reports/v13_4_19_probability_bucket_coarsening_report.json`
- `reports/v13_4_19_probability_score_table_coarse_c.json`
- `reports/v13_4_19_probability_score_table_coarse_d.json`

## Candidate Configs

V13.4.20 creates three candidate configs under
`configs/probability_gate_candidates/`.

| Candidate | Source table | Allowed bucket | Status |
| --- | --- | --- | --- |
| `probability_gate_c1_trend_medium_safe` | coarse C | `trend_medium_safe` | `research_only` |
| `probability_gate_d1_trend_module_low_safe` | coarse D | `trend_trend_module_low_safe` | `research_only` |
| `probability_gate_cd_trend_research_combined` | coarse C + coarse D | `trend_medium_safe`, `trend_trend_module_low_safe` | `research_only` |

Every candidate config keeps:

- `useForTrading: false`
- `useForDryRun: false`
- `entryAllowed: false`

These configs are intended only as explicit inputs for the next comparative
backtest plan.

## Rejected Diagnostic Buckets

The following buckets are intentionally kept as diagnostic-only and must not be
promoted to entry candidates from bucket-level research results:

- `avoid_low_weak`
- `unknown_no_entry_module_low_safe`

They are useful for understanding the sparse probability table, but their
labels indicate an avoid, unknown, or no-entry context. V13.4.20 preserves them
in reports as rejected diagnostics only.

## Loader Validation

The loader in `alphapilot/probability/probability_gate_candidate_loader.py`
validates that:

- candidate status is `research_only`
- `useForTrading` is false
- `useForDryRun` is false
- at least one allowed bucket exists
- source table files exist
- allowed buckets do not contain forbidden diagnostic terms such as `avoid`,
  `unknown`, or `no_entry`

Illegal bucket promotion raises `ValueError`.

## Outputs

```powershell
python -m alphapilot.reports.generate_probability_gate_candidate_plan
```

Outputs:

```text

```

## Boundary

V13.4.20 is wiring and planning only. A candidate gate is not a trading gate,
not a Dry-run approval, not a live signal, and not an order instruction.

The next version should be V13.4.21: Probability Gate Candidate Backtest.
