# AlphaPilot V13.25.0 - Fail-Closed OKX Live Canary

V13.25 adds the technical Live Canary adapter and immutable `LiveRelease`
contract. It does not claim any strategy is profitable or ready for Live use.

## Release gate

A LiveRelease can only be created from a checksum-matched Live candidate, an
active `live_canary` RiskProfile, and timestamped `user_manual` approval. The
release binds all lineage, approval, strategy, risk, rollback, and protection
hashes. New risk or strategy versions require a new release.

## Runtime gate

The Console remains fail-closed until all process switches, process-only
credentials, approved release, matching RiskProfile, private-state
reconciliation, and manual ARM are present. Every order requires isolated
margin, attached TP and SL, at least 2R, idempotency, restart recovery, and
account-level risk checks. Unknown state pauses new entries.

Withdraw is absent. V13.25 tests use fake transports and place no real order.
