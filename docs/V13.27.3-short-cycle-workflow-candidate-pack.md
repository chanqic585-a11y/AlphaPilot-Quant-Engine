# AlphaPilot V13.27.3 - Short-Cycle Workflow Candidate Pack

## Purpose

V13.27.3 adds ten research candidates to exercise the complete controlled
lifecycle without pretending that candidate registration is strategy proof.

The pack contains five 5-minute and five 15-minute strategies across breakout,
EMA reclaim, mean-reversion reclaim, short breakdown, short rejection,
momentum continuation, and low-volatility compression families.

## Timeframe Semantics

- A 5-minute strategy makes decisions and evaluates exits on completed
  5-minute candles.
- A 15-minute strategy makes decisions on completed 15-minute candles and
  evaluates its execution horizon on 5-minute candles.
- BTC context uses the same completed signal timeframe.
- Incomplete candles never create formal signals.

## Formal Universe

Formal backtests use a historical point-in-time dynamic Top50 universe. At each
historical decision point, only then-known instrument status and liquidity may
enter the eligible set. Today's static Top50 must not be projected backward.

A single instrument is permitted for smoke/debug only and cannot satisfy a
formal promotion gate.

## Workflow Controls

The CLI supports serial selected operations:

```powershell
python -m alphapilot.evolution.workflow.cli run-selected-backtests --run-id RUN_1 --run-id RUN_2
python -m alphapilot.evolution.workflow.cli run-selected-forward-cycles --run-id FORWARD_1 --run-id FORWARD_2
```

Each local-forward run retains its immutable release, virtual account, session,
state checkpoint, and outcome ledger. A repeat cycle reads completed public
candles and cannot manufacture a new closed sample from an unchanged candle.

## Safety

- Candidate registration creates no Demo or Live release.
- Local forward uses public data only and creates no exchange order.
- Batch controls do not bypass formal evidence, `targetR >= 2`, immutable
  release, risk, idempotency, or reconciliation gates.
- No raw credential is stored.
- Live remains locked by the existing independent release and runtime gates.
