# AlphaPilot V13.5.23 - Alpha191 Crypto-Safe Subset Replay

V13.5.23 implements a small Alpha191-inspired crypto-safe factor subset and
tests it against AlphaPilot's existing local historical replay gates.

This version does not copy Alpha191 formulas. It uses the V13.5.22 metadata
catalog as a research guide, then implements compact OHLCV-derived features
that can be audited directly in AlphaPilot.

```text
alphapilot/factors/alpha191_crypto_safe_subset.py
```

The subset includes:

- rolling return-volume correlation

These are concept-inspired crypto features. They are not copied formulas.
