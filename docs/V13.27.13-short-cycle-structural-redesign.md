# V13.27.13 Short-Cycle Structural Redesign

V13.27.13 archives the prior Alpha191 observer and ten V13.27.3 short-cycle
versions after their bounded optimization campaigns ended in
`development_structurally_weak`.

The observed failure pattern was consistent: profit factors ranged from about
0.25 to 0.70, average net R was negative, and several definitions generated
excessive trade counts. The replacement pack therefore changes signal
structure instead of relaxing promotion gates.

The six new research candidates are:

- `5m 顺势回踩确认 ATR1.0`
- `5m 压缩放量释放 ATR1.1`
- `5m 弱势反抽失败 ATR1.0`
- `15m 顺势回踩确认 ATR1.2`
- `15m 压缩放量释放 ATR1.3`
- `15m 弱势反抽失败 ATR1.2`

Each candidate combines direction-aligned EMA structure with completed-candle
confirmation, volume and ATR-range filters, and the existing BTC shock guard.
All six retain `targetR = 2.0`, use the opt-in 2R half-exit plus ATR runner, and
start at `backtest / awaiting`. They cannot create a Forward, Demo, or Live
release without passing the existing immutable gates.

A bounded signal smoke over recent official BTC, ETH, and SOL public OHLCV
confirmed that every definition can produce signals without returning to the
old pack's broad trigger rates. This smoke is implementation evidence only; it
is not profitability evidence and does not replace the formal dynamic-universe
walk-forward backtest.

No private exchange endpoint, credential, account state, position state,
order, Demo release, Live release, or automatic promotion is introduced.
