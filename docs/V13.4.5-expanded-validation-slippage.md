## Slippage Model

V13.4.5 does not apply slippage inside Freqtrade.

The AlphaPilot report applies slippage after the backtest:

```text
slippageRateOneWay = 0.0005
roundTripSlippage = 0.001
slippageAppliedByFreqtrade = false
slippageAppliedByPostProcessing = true
```

For each trade, the report subtracts a round-trip slippage cost from the Freqtrade trade result. If order cost is available, it uses order cost. If not, it falls back to a notional estimate and records a warning.

Post-processed drawdown can exceed 100% because the adjustment is applied after Freqtrade without a liquidation model. This is intentionally conservative and is not a live trading simulation.

## Decision

V13.4.5 does not approve Dry-run.

The expanded sample confirms that B/C/E remain weak after slippage. C is the best relative candidate by profit factor, but the slippage-adjusted total return is still deeply negative.

The recommended next step is V13.4.6 strategy direction review or V03 redesign, not Dry-run.
