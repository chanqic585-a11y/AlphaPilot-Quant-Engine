# AlphaPilot V13.22.0 Offline Evolution Feedback Loop

## Purpose

V13.22 turns immutable outcome evidence into offline research diagnostics and
bounded challenger generation. It does not perform online learning and does not
modify a running strategy.

## Evidence classes

- `historical_path_replay`: formal actual-candle historical replay.
- `realtime_local_forward`: public-market event-time local forward observation.
- `okx_demo`: checksum-bound OKX Demo lifecycle outcomes.
- `live`: reserved for a future explicitly approved Live release.

`historical_path_replay_probe`, legacy synthetic, synthetic forward, unknown,
invalid-time, mismatched-class, and incomplete-lineage records are quarantined.
They remain auditable but never enter performance totals or evolution triggers.

## Diagnostics

For each formal evidence class and the combined formal set, the loop reports:

- sample and metric availability;
- net R, mean R, win rate, and profit factor;
- fixed-2R target-hit and stop rates;
- fee/slippage cost drag;
- same-bar ambiguity;
- symbol and month concentration;
- chronological early-versus-recent factor decay.

## Bounded research path

Formal closed evidence and an actionable failure mode may start bounded factor
mutation. Generated factors remain `shadow_research`; correlation filtering
requires real materialized factor values and never imputes or invents them.
Champion/challenger comparison can request shadow review only. A new strategy
candidate requires complete registered snapshot, FactorRun, experiment, purged
walk-forward, fixed `>=2R`, and formal gate evidence.

## Immutability and rollback

ForwardRelease, DemoRelease, and LiveCandidatePackage hashes are captured before
and after every loop. Any change raises an error. Existing positions remain
bound to their original release, new entries stop before rollback, and no Live
rollback is automatic.

No API key, Trade API, Withdraw API, account/position read, order creation,
automatic promotion, online model mutation, or running-release replacement is
added.
