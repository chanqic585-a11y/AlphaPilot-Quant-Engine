# V13.5.1 - Expanded Relaxed Derivatives Research

V13.5.1 expands the V13.5 derivatives research pipeline to all locally
available futures pairs and adds a relaxed shadow-watchlist gate.

This version still does not approve paper, Dry-run, or live trading unless the
strict hard gate passes. A relaxed candidate is only a research watchlist item.

## Gates

Hard gate:

- trade count >= 100
- win rate >= 55%
- reward/risk >= 1.8
- profit factor >= 1.35
- max drawdown <= 20%
- positive after fees and slippage

Relaxed shadow-watchlist gate:

- trade count >= 80
- win rate >= 52%
- reward/risk >= 1.4
- profit factor >= 1.2
- max drawdown <= 35%
- positive after fees and slippage

Observation gate:

- trade count >= 50
- win rate >= 50%
- reward/risk >= 1.2
- profit factor >= 1.1
- max drawdown <= 45%

## Expanded Universe

When no pair list is provided, V13.5.1 auto-discovers local OKX futures data
for the selected timeframe under `user_data/data/okx/futures`.

This makes the report use the locally available universe without pretending
that missing pairs exist. Open interest remains `unavailable_not_fabricated`
unless a public local file exists.

## Run

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_1_expanded_relaxed_research.ps1 -Timeframe 1h -Run
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_1_expanded_relaxed_research.ps1 -Timeframe 4h -Run
```

## Safety Boundary

V13.5.1:

- uses local public market data only
- does not use API keys
- does not call Trade API
- does not call Withdraw API
- does not read accounts
- does not read positions
- does not create orders
- does not auto trade
