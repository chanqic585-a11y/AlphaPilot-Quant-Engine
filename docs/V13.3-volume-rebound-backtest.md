# V13.3 Volume Rebound Backtest Foundation

V13.3 implements the first AlphaPilot research strategy for baseline
Freqtrade backtesting:

```text
AlphaPilot Volume Rebound V0.1
```

This version is research-only. It does not trade live, does not use real API
keys, does not read a real account, and does not create real orders.

## Fixed Parameters

- Market: OKX USDT swap
- Direction: long only
- Timeframe: 15m
- Universe: fixed Top 30 USDT swap pairs
- Leverage: 5x research cap
- Stoploss: -3%
- Take profit: +3% full exit
- Risk per trade: 1% documented research assumption
- Fee rate: 0.05% one-way
- Slippage rate: 0.05% one-way planned in report schema

## Strategy Logic

Entry requires all V0.1 conditions:

- BTC is not in the crash filter.
- Current pair 4h trend is not strongly bearish.
- RSI14 is between 30 and 55.
- `volumeRatio >= 1.5`.
- MACD histogram is improving.
- Close is near or above EMA20.
- Price is not extended above the Bollinger middle band.

Exit uses:

- Freqtrade fixed stoploss at -3%.
- Freqtrade minimal ROI at +3%.
- MACD histogram two-candle weakness exit signal.
- Custom time stop after 12 candles if the trade is still not profitable.

## Backtest Assumptions

V13.3 strategy implementation follows Freqtrade's backtest assumption that
signals are generated on candle close and entries are handled by the engine on
the next candle. The strategy uses rolling and shift operations and avoids
`iloc[-1]` for historical signal generation.

## Execution

Scripts print commands by default.

Download smoke data:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/download_data.ps1 -Pairs "BTC/USDT:USDT,ETH/USDT:USDT,SOL/USDT:USDT" -Timeframes "15m,1h,4h" -Timerange "20240101-"
```

Run smoke backtest command preview:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_backtest.ps1 -Smoke -Timerange "20240101-20240701"
```

Add `-Run` only when Docker and Freqtrade are ready.

Export report:

```powershell
python -m alphapilot.reports.export_backtest_report
```

If a Freqtrade JSON result exists in `user_data/backtest_results`, the exporter
tries to convert it to `reports/latest_backtest_report.json` with
`isMock=false`. If no real result exists, it creates
`reports/sample_backtest_report.json` with `isMock=true`.
