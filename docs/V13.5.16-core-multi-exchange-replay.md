# AlphaPilot V13.5.16 - Core Multi-Exchange Replay

V13.5.16 replays the fixed active V13.5.7 research pool on local public BTC/ETH/SOL data across OKX, Binance, and Bybit.

This version does not tune the strategy. It does not download data, run exchange Dry-run, connect to private exchange endpoints, create orders, or approve live trading.

## Active Pool

```text
4h:alpha_short_exhaustion_pressure_watch:sl0.06:h24
```

The active pool keeps:

- timeframe: 4h
- stop loss: 6%
- reward target: 2R
- horizon: 24 bars
- round-trip fee assumption: 0.1%
- round-trip slippage assumption: 0.1%

## Commands

Preview:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_16_core_multi_exchange_replay.ps1
```

Generate reports:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_16_core_multi_exchange_replay.ps1 -Run
```

Outputs:

```text
reports/v13_5_16_core_multi_exchange_replay_report.json
reports/v13_5_16_core_multi_exchange_replay_summary.md
reports/v13_5_16_core_multi_exchange_signal_log.json
```

## What This Proves

The report proves that the existing feature and event pipeline can be pointed at exchange-specific local public data directories:

```text
user_data/data/okx/futures
user_data/data/binance/futures
user_data/data/bybit/futures
```

It also measures whether the fixed active pool produces enough historical events across independent public exchange samples.

## What This Does Not Prove

- It does not prove future profitability.
- It does not approve Dry-run.
- It does not approve live trading.
- It does not replace forward validation.
- It does not make any trade recommendation.

## Safety Boundary

- No Trade API.
- No Withdraw API.
- No API key storage.
- No real account reads.
- No real position reads.
- No order creation.
- No automatic trading.

## Next Step

If the core replay sample is too small, the next step is not parameter overfitting. The next step is to expand exchange-aware data coverage in smaller resumable batches and repeat the same fixed-pool replay.
