# AlphaPilot V13.27.6 - Official Data Progress

Long OKX public-history downloads now publish a durable active-partition
checkpoint after the first page, every 25 pages, and the final page.

The checkpoint records:

- instrument and timeframe
- requested pages and maximum page budget
- collected K-line rows
- oldest received timestamp
- latest update time

Workflow projection reports this telemetry separately from the overall workflow
phase percentage. Completing or failing a partition removes its active entry.
Pausing keeps the latest progress visible. Partial rows never enter the
completed partition registry and never become formal backtest evidence.

This patch does not change strategy definitions, `targetR >= 2`, exchange
permissions, raw credential handling, Withdraw, or Live execution.
