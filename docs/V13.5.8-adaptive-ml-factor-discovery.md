# V13.5.8 Adaptive ML Factor Discovery

V13.5.8 adds an auditable adaptive machine-learning layer to AlphaPilot's
research pipeline.

The goal is not to create an auto-trading system. The goal is to let AlphaPilot
learn candidate factor rules from prior historical segments and validate them
on later segments, then report whether the result is strong enough for local
paper watch.

## ML Approach

The current environment does not include sklearn, xgboost, lightgbm, or
catboost. V13.5.8 therefore uses a lightweight, auditable learner:

1. Build local public derivatives feature panels.
2. Add the V13.5.7 Alpha101-style factor overlay.
3. Build high-reward event labels with the existing 2R triple-barrier logic.
4. Split the event stream into walk-forward folds.
5. For each fold, learn simple factor-threshold rules from prior data only.
6. Apply learned rules to later data only.
7. Report selected-event metrics, baseline metrics, fold stability, and rule
   performance.

The learner can use contexts such as:

```text
direction
setupName
btc_regime
setupName + btc_regime
```

Then it learns factor thresholds inside those contexts.

Interpretation:

- The adaptive layer improved the baseline slightly, but it is still negative.
- Full adaptive candidates are not safe enough for local paper watch.
- Some single learned rules show positive future-fold metrics, but their sample
  sizes are too small and fold coverage is too narrow.
- V13.5.7's fixed 4h alpha overlay remains the only current local paper watch
  line.

## Strategy Evolution Sample Schema

V13.5.8 adds `strategy_evolution_sample_v1` as a future data contract.

It can store:

- historical labeled outcomes
- local paper outcomes
- manual trade-review outcomes
- future manually approved execution outcomes

It must not be used to create automatic orders. Samples can only improve future
offline research after validation.

## Safety Boundary

V13.5.8 does not:

- use API keys
- call Trade API
- call Withdraw API
- read real accounts
- read real positions
- create orders
- auto trade
- approve exchange Dry-run
- approve live trading

V13.5.8 only adds offline adaptive factor research and a future sample schema.
