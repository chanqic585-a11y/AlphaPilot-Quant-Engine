# AlphaPilot V13.4.31 - Low-Frequency Mainstream Coin Research Plan

V13.4.31 moves AlphaPilot back to a simpler, lower-frequency mainstream-coin research track after the V13.4.29 short-only 1h failure and V13.4.30 negative-rule review.

This version is a research plan only. It does not implement a strategy, download data, run a backtest, enter Dry-run, use API keys, or approve live trading.

## Scope

Main pairs:

```text
BTC/USDT:USDT
ETH/USDT:USDT
SOL/USDT:USDT
```

Primary timeframes:

```text
4h
1d
```

Optional informative timeframe:

```text
1h
```

First version excludes Top30 expansion, new listings, low-liquidity altcoins, and broad high-frequency 15m/1h signal loops.

## Direction

Long and short can both be researched, but they must be evaluated as separated modules.

Market regime is a context input for scoring and risk weighting. It is not the only hard switch.
