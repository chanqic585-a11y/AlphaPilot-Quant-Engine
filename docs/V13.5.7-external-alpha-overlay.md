# V13.5.7 External Alpha Overlay Research

V13.5.7 reviews two public GitHub projects as research references and adds a
compact Alpha101-style factor overlay to AlphaPilot's existing high-reward event
pipeline.

This version is research-only. It does not copy external code, does not copy
long source text, and only stores URL/license/summary/citation metadata for the
external references.

## External References

### yydhYYDH/alpha101

- URL: https://github.com/yydhYYDH/alpha101
- License: unknown from raw license fetch during this run
- Summary: crypto factor research toolkit with Alpha101-style factor
  expressions, factor panels, factor evaluation, search, backtesting, and
  Freqtrade-based public kline data ingestion.
- AlphaPilot usage: concept reference only for cross-sectional ranks,
  time-series ranks, rolling correlation, decay-style factors, and explicit
  research-only boundaries.

### ryckli/CryptoAgentPro.beta

- URL: https://github.com/ryckli/CryptoAgentPro.beta
- License: MIT
- Summary: crypto strategy research architecture with strategy modules,
  backtesting, AI context, paper/testnet separation, and a risk gateway concept.
- AlphaPilot usage: concept reference only for strict mode separation, public
  data first workflows, and risk gateway thinking. No execution integration was
  adopted.

## Added Research Layer

V13.5.7 adds:

```text
alphapilot/factors/alpha101_style_overlay.py
alphapilot/reports/generate_v13_5_7_external_alpha_overlay_report.py
scripts/run_v13_5_7_external_alpha_overlay.ps1
reports/v13_5_7_external_alpha_overlay_report.json
reports/v13_5_7_external_alpha_overlay_summary.md
reports/v13_5_7_alpha_overlay_candidates.json
```

The overlay computes:

- cross-sectional ranks by timestamp
- per-pair rolling time-series ranks
- rolling return-volume correlation
- decay-style return and volume-pressure features
- rebound pressure, exhaustion pressure, and liquidity quality composites

These factors are applied after the existing derivatives feature panel is built
and before high-reward event labels are summarized.
