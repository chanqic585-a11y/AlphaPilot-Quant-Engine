# AlphaPilot V13.27.1 - Strategy Backtest Workflow

V13.27.1 connects the immutable V13.27.0 workflow records to real, local
backtest work. It does not promote a strategy by changing a label. A worker
must produce a manifest-bound result, and the central gate evaluator decides
whether that immutable strategy version passed.

## Backtest authority

The implementation lives in:

```text
alphapilot/evolution/workflow/backtest.py
alphapilot/evolution/workflow/bootstrap.py
alphapilot/evolution/workflow/cli.py
```

Each run binds:

- the immutable strategy content hash;
- a registered point-in-time `DataSnapshot`;
- a purged walk-forward manifest;
- a locked out-of-sample manifest;
- an explicit fee and slippage model;
- a versioned `GateProfile`;
- the fixed target of at least `2R`.

Missing or ineligible lineage blocks the run before an adapter starts. The
worker never substitutes a default good result for missing data.

## Restart and concurrency behavior

- A queued run may be claimed by one worker.
- A second normal worker is rejected while the run is already active.
- Runs that share a fixed-output adapter are serialized by a cross-process
  adapter lock so one report cannot overwrite another.
- Recovery is explicit through the `recover` command.
- Manifest, progress checkpoints, and the result artifact are written
  atomically under `data/workflow/backtests/<workflowRunId>/`.
- A paused run can reuse a verified result artifact instead of rerunning the
  adapter.
- Pause or cancel terminates the active local adapter process; it is not only a
  display-state change.
- Operational failures may retry the same immutable version.
- Performance failures require a changed challenger version and restart at
  backtesting.

## Local command boundary

```powershell
python -m alphapilot.evolution.workflow.cli bootstrap
python -m alphapilot.evolution.workflow.cli projection
python -m alphapilot.evolution.workflow.cli queue --run-id <workflowRunId>
python -m alphapilot.evolution.workflow.cli run --run-id <workflowRunId>
python -m alphapilot.evolution.workflow.cli recover --run-id <workflowRunId>
python -m alphapilot.evolution.workflow.cli pause --run-id <workflowRunId>
python -m alphapilot.evolution.workflow.cli cancel --run-id <workflowRunId>
python -m alphapilot.evolution.workflow.cli retry --run-id <workflowRunId>
```

The CLI accepts fixed commands and allowlisted adapter identifiers. It does not
accept arbitrary shell commands.

## Current imported observer

The legacy Alpha191 observation asset is registered as one immutable strategy
version named `Alpha191 加密因子观察策略`. It intentionally remains
`backtest / awaiting` until a formal point-in-time snapshot and evaluation
manifests are bound. Running it without those prerequisites records a precise
data-integrity blocker; it cannot create a false pass.

## Safety boundary

V13.27.1 backtesting reads local research data and launches only allowlisted
local report adapters. It does not store credentials, call Trade API or
Withdraw API, create Demo or Live orders, enable automatic trading, or turn a
backtest result into an automatic stage promotion.
