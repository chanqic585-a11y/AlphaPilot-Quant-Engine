# V13.27.1.34C Public Data Scheduler

V34C turns the V34B one-shot public collector into a resumable foreground service. It schedules only due public-data work and preserves the immutable V34A/V34B identities.

## Scheduled Streams

| Task | Default cadence |
| --- | ---: |
| Instrument metadata | 24 hours |
| Funding increment | 1 hour |
| Instrument state | 1 hour |
| Current funding | 15 minutes |
| Open interest | 15 minutes |
| Mark price | 5 minutes |
| Index price | 5 minutes |
| Ticker spread | 5 minutes |
| Order-book summary | 5 minutes |
| Quality report | 15 minutes |

Each task has durable `nextDueAt`, success/failure state, bounded retry timing, and artifact identity. A single-owner lease prevents two service processes from writing the same scheduler state concurrently.

## Run Once

```powershell
cd D:\Codex-Workspace\AlphaPilot-Quant-Engine
python -m alphapilot.scripts.run_v34c_okx_public_data_service `
  --warehouse-root D:\Codex-Workspace\回测数据 `
  --program-root reports\dual_track\<programId> `
  --base-snapshot-id <v34aSnapshotId> `
  --mode once
```

## Run Foreground Loop

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_v34c_public_data_service.ps1 `
  -ProgramRoot reports\dual_track\<programId> `
  -BaseSnapshotId <v34aSnapshotId> `
  -WarehouseRoot D:\Codex-Workspace\回测数据 `
  -Mode loop
```

The loop sleeps only after a completed cycle. `Ctrl+C` records an operator stop. A `V34C_PAUSE_REQUESTED` file under the warehouse checkpoints directory pauses new cycles safely. The launcher does not daemonize itself or install an operating-system task.

## Safety Boundary

V34C uses only public OKX market endpoints. It does not read accounts, save credentials, place orders, generate candidates, run Formal validation, read Locked OOS evidence, create Releases, approve Demo, ARM execution, or change Live gates.
