# AlphaPilot V13.4.29 Short Rejection 1H Research Strategy

V13.4.29 adds `AlphaPilotShortRejection1HV01`, a short-only 1h Freqtrade
research strategy. It directly runs real local Freqtrade smoke and expanded
backtests using public historical OKX futures data.

This is not Dry-run, live trading, a production strategy, or a recommendation.
It does not use real API keys, private exchange APIs, account reads, position
reads, order creation, or auto trading.

## Strategy File

```text
user_data/strategies/AlphaPilotShortRejection1HV01.py
```

Core parameters:

```text
timeframe = 1h
can_short = True
stoploss = -0.025
minimal_roi = {"0": 0.05}
direction = short only
```

account-level collapse in the expanded sample. This should be treated as a
