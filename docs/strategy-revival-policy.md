# Strategy Revival Policy

An archived strategy is a negative research asset, not a paused executable.

## Allowed revival path

1. Create a new immutable strategy/version ID.
2. State a materially different hypothesis when the prior signal edge was
   structurally negative.
3. Fill all required evidence gaps.
4. Demonstrate positive average net R and profit factor above 1 on development
   evidence.
5. Pass realistic fees/slippage, holdout, Walk-forward, and locked-data
   isolation checks.
6. Pass account-path risk independently.
7. Enter the normal promotion workflow as a new candidate.

## Prohibited revival

- Editing an archived report in place.
- Treating a parameter tweak as new evidence.
- Reusing locked/holdout data for selection.
- Promoting because one pair or one month looked positive.
- Reviving Martingale or inverse-averaging risk designs.
- Using this analysis report as a Demo or Live release.

The generated revival file records conditions only. It never modifies strategy
code or creates an executable candidate.
