# V13.4.23 Benchmark Strategy Suite

V13.4.23 implements the Benchmark Strategy Suite as a research-only comparison
layer for AlphaPilot strategy work.

The suite answers one question:

```text
How do transparent benchmark rules perform on the selected historical sample?
```

It does not answer whether a strategy should be used in Dry-run or live trading.

## Implemented Scope

- Freqtrade benchmark strategy file:
  `user_data/strategies/AlphaPilotBenchmarkStrategies.py`
- Benchmark registry:
  `alphapilot/benchmarks/benchmark_registry.py`
- Benchmark runner wrapper:
  `scripts/run_benchmark_suite.ps1`
- Benchmark report generator:
  `alphapilot/reports/generate_benchmark_suite_report.py`
- Research reports:
  `reports/v13_4_23_benchmark_suite_report.json`
  `reports/v13_4_23_benchmark_suite_summary.md`
  `reports/v13_4_23_benchmark_manifest.json`

## Benchmark Set

```text
BenchmarkNoTrade
BenchmarkBuyHoldBTC
BenchmarkEMATrend
BenchmarkRSIMeanReversion
BenchmarkMACDVolume
BenchmarkBollingerRebound
BenchmarkTD9Exhaustion
```

Martingale / inverse averaging is recorded only as a rejected benchmark idea.

## Default Research Run

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_benchmark_suite.ps1 -UseTop10 -Timerange "20260101-" -Run
python -m alphapilot.reports.generate_benchmark_suite_report
```

The first implementation uses the local OKX USDT swap data already downloaded
for research. No exchange private endpoints are used.

## Safety Boundary

```text
dryRunApproved: false
liveTradingApproved: false
no Trade API / Withdraw API
no real API key
no account / position reads
no real orders
no auto trading
```

The benchmark suite is a comparison tool, not a trading system.
