# V13.4 Real Freqtrade Smoke Backtest

V13.4 is intended to run the first real Freqtrade smoke backtest for
AlphaPilot Volume Rebound V0.1.

This version is not a strategy tuning version and not a live trading version.
It does not use real API keys, does not read a real account, and does not
create real orders.

## Current Runtime Status

V13.4 real smoke execution is complete.

Docker Desktop was installed locally, public OKX historical futures data was
downloaded, Freqtrade backtesting completed, and the AlphaPilot exporter created
real reports with `isMock=false`.

The fixed version report is:

```text
reports/v13_4_smoke_backtest_report.json
```

Dynamic rerun outputs are ignored:

```text

reports/smoke_backtest_report.json
```
