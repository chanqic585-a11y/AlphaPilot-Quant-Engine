# V13.4 Real Freqtrade Smoke Backtest

V13.4 is intended to run the first real Freqtrade smoke backtest for
AlphaPilot Volume Rebound V0.1.

This version is not a strategy tuning version and not a live trading version.
It does not use real API keys, does not read a real account, and does not
create real orders.

In the current Codex environment, `docker` is not available on PATH. Because of
