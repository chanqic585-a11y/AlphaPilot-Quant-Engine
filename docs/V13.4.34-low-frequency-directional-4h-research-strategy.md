# V13.4.34 Low-Frequency Directional 4H Research Strategy

V13.4.34 implements the first real low-frequency directional research strategy for BTC/ETH/SOL 4h public OHLCV backtesting.

This version is research-only:

- no Dry-run approval
- no live trading approval
- no real API key
- no Trade API / Withdraw API
- no account or position reads
- no real orders
- no auto trading

## Strategy

Strategy class:

```text
AlphaPilotLowFrequencyDirectional4HV01
```

Main files:

```text
user_data/strategies/AlphaPilotLowFrequencyDirectional4HV01.py
scripts/run_low_frequency_directional_backtest.ps1
alphapilot/reports/generate_low_frequency_directional_report.py
```

The strategy uses:

- EMA20 / EMA50 / EMA200
- RSI14
- MACD histogram
- ATR14
- volumeRatio
- recent 3-candle return
- long and short score gates
- no-chase blockers
- fixed -3% stoploss
- fixed +6% ROI
- custom time and momentum exits

The strategy failed the research hurdle. It does not beat NoTrade, does not beat EqualWeight BTC/ETH/SOL, and does not survive post-processing slippage stress.

## Interpretation

V13.4.34 is useful because it produced a real negative result instead of a paper design assumption.

The current score-gate design fires too often, loses too frequently, and compounds losses across long and short entries. This should not be promoted to Dry-run or live use.

Future work should reduce trade frequency, add stronger regime filtering, and treat NoTrade as an active defensive outcome.
