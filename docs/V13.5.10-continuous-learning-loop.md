# V13.5.10 Continuous Learning Loop

V13.5.10 starts the AlphaPilot continuous learning loop by converting local
paper outcomes into strategy evolution samples.

This version does not retrain a model and does not approve any execution mode.
It prepares evidence so future versions can decide whether offline retraining is
justified.

## Retraining Gate

Retraining review is blocked until these conditions improve:

```text
minimum usable local paper samples >= 100
active strategy closed local paper samples > 0
closed fills are fresh
monitoring health is healthy
```

Current fail reasons:

```text
insufficient_usable_local_paper_samples
active_strategy_has_no_closed_local_paper_samples
closed_fill_not_fresh
```

## Cross-Market Sample Expansion Direction

The next learning-loop expansion may add public, non-crypto research samples,
including A-share, Hong Kong stock, US equity, ETF, and index data.

These samples should be used as:

```text
cross-market factor research samples
market-regime references
volatility and liquidity analogs
feature robustness tests
```

They must not be mixed into crypto execution decisions without explicit
cross-market labeling, normalization, and validation. Stock-market samples are
research context, not crypto trade commands.

## Safety Boundary

V13.5.10 does not add:

```text
Trade API
Withdraw API
API key storage
real account reads
real position reads
real order creation
emergency close execution
testnet execution
automatic trading
```
