# AlphaPilot V13.5.20 - Exit-Aware Loss Cooldown

V13.5.20 evaluates exit-aware portfolio cooldown policies on the V13.5.18 historical signal log.

This version does not change entry logic, does not change the 2R target, and does not tune strategy parameters.

## Input

```text
reports/v13_5_18_non_okx_expansion_signal_log.json
```

## Core Rule

Loss cooldown starts only after a selected historical trade has closed:

```text
cooldown trigger time = exitDate
```

It must not start at `entryDate`, because that would use future outcome information before the trade result is known.
