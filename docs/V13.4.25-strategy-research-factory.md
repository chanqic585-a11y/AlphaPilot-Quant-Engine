# AlphaPilot V13.4.25 Strategy Research Factory

V13.4.25 creates the first Strategy Research Factory hypothesis registry.

It reads existing local research outputs only:

- `reports/v13_4_22_factor_evaluation_report.json`
- `reports/v13_4_22_factor_candidates.json`
- `reports/v13_4_23_benchmark_suite_report.json`
- `reports/v13_4_24_benchmark_result_review.json`
- `reports/v13_4_24_benchmark_status_archive.json`

It does not write a Freqtrade strategy, does not run a backtest, and does not
approve Dry-run or live trading.

## Outputs

```text
reports/v13_4_25_strategy_research_factory_report.json
reports/v13_4_25_strategy_research_factory_summary.md

```

## Why This Version Exists

V13.4.23 showed that the simple benchmark strategy families were not usable.
V13.4.24 confirmed that all active benchmarks failed against NoTrade and
BuyHoldBTC after cost stress.

V13.4.25 prevents the project from jumping directly into more strategy code. It
turns the evidence into a structured set of hypotheses that can be validated in
the next version.
