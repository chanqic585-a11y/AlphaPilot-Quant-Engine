# AlphaPilot V13.4.27 Market Regime and Data Integrity Review

V13.4.27 is a research-only checkpoint before any further data expansion or
strategy research.

It answers two questions:

1. Are the local public OKX OHLCV files reliable enough for research?
2. Did recent market regime conditions make long-only technical strategies
   broadly fragile?

It does not implement a strategy, run a Freqtrade backtest, download new data,
enter Dry-run, call exchange private APIs, read accounts, create orders, or
auto trade.

## Outputs

```text
reports/v13_4_27_market_regime_data_integrity_report.json
reports/v13_4_27_market_regime_data_integrity_summary.md
reports/v13_4_27_btc_regime_labels.json
reports/v13_4_27_data_quality_by_pair.json
```

Run:

```powershell
python -m alphapilot.reports.generate_market_regime_data_integrity_review
```

## Initial Result

The first local run completed with warnings:

```text
status = completed_with_warnings
dataIntegrity.status = warning
timeframesChecked = 1h, 4h
pairCount = 30
missingFileCount = 4
invalidCount = 0
totalInvalidOhlcRows = 0
totalDuplicateTimestamps = 0
```

The missing local files are treated as warnings, not fabricated data. The
review keeps them visible so later data expansion can repair the gap.

## Market Regime Finding

BTC regime labels for the selected local sample show a material mix of bear,
sideways, bull, and high-volatility conditions. This means prior long-only
technical strategy failures should not be interpreted as a simple parameter
problem.

The V13.4.27 conclusion is:

```text
Local OHLCV quality appears usable for research if warnings are reviewed, but
the selected sample is strongly regime-sensitive. Recent long-only technical
research failures are more consistent with adverse bear/high-volatility market
context plus sparse validated alpha than with a single obvious data corruption
issue.
```

## Required Boundary

V13.4.27 keeps all approval flags false:

```text
dryRunApproved = false
liveTradingApproved = false
strategyImplemented = false
backtestExecuted = false
dataDownloaded = false
```

Future strategy reports should include regime tags per sample or per trade so
strategy quality can be separated from market-regime exposure.
