# AlphaPilot V13.27.1.37A - Funding Carry Data Readiness

## Objective

Close the data-capability blocker for the preregistered `crypto_funding_carry_v1`
family. Build an auditable, same-exchange OKX Spot/Perpetual/Funding panel with
causal timestamps, dual-leg cost stress, and capacity semantics. This stage is
data-only: it does not generate a candidate, run Formal validation, create a
Release, ARM Demo, or place an order.

## Existing Capabilities To Reuse

- V34A immutable OKX SWAP OHLCV partitions and manifests.
- V34B/V34C public funding, PIT metadata, current market state, order-book
  summaries, incremental collection, and scheduler evidence.
- V36 official monthly OKX funding archive backfill and recent public tail.
- Existing backward as-of basis and capacity-semantics helpers.

V37A must not duplicate these collectors or mutate their frozen artifacts.

## Missing Capability

1. Audited OKX Spot OHLCV for the same base assets and observation interval.
2. A causal alignment contract joining confirmed Spot and Perpetual candles to
   realized funding observations without forward joins or zero filling.
3. Explicit dual-leg cost stress and quote-turnover capacity semantics.
4. Separate historical-research readiness and forward-execution-evidence
   readiness decisions.

## Frozen Pilot Policy

- Exchange: OKX Global public endpoints only.
- Assets: BTC, ETH, SOL.
- Instruments: matching `*-USDT` Spot and `*-USDT-SWAP` Perpetual pairs.
- Alignment timeframe: 1h UTC confirmed candles.
- Historical start: 2022-03-01 UTC, matching documented OKX funding archive
  availability.
- Funding observations are usable no earlier than `fundingTime`.
- Missing rows remain missing; no cross-exchange substitution and no zero fill.
- Cost values are preregistered stress assumptions, never account fee claims.
- Historical quote turnover is a capacity proxy, not historical L2 evidence.

## Acceptance Gates

- Every reused input has a traceable manifest and matching SHA-256.
- Spot and Perpetual data are from OKX and share the same base/quote pair.
- Funding is actual OKX history with causal availability timestamps.
- Every aligned row is backward-only and carries source-lag evidence.
- Both legs expose verified quote-turnover semantics or readiness is blocked.
- Dual-leg fee/slippage values are labeled policy stress assumptions.
- Historical and forward readiness are reported independently.
- Candidate, Formal, result-read, Release, approval, Demo ARM, and order counts
  remain zero.
- Trade API, Withdraw API, credentials, account reads, positions, and orders
  remain absent.
- Targeted tests, full test suite, compile, config validation, safety scan, and
  `git diff --check` pass.

## Execution Order

1. Write failing tests for contracts, no-lookahead, manifest verification,
   missing evidence, and zero side effects.
2. Implement the smallest code required to pass each test.
3. Run audit-only mode against the approved warehouse.
4. If and only if Spot is the remaining blocker, run the bounded BTC/ETH/SOL
   public Spot collection and resume safely until complete.
5. Generate immutable readiness evidence and close out without starting a
   strategy experiment.
