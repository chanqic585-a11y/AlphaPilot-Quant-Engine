# V13.27.1.17 Phase 1 Prerequisite Freeze

## Objective

Freeze the contracts required to run S01 formal Purged Walk-forward without
reading Campaign Locked OOS or producing any promotion, Demo, or order artifact.

## Decision

Readiness is split into two independent gates:

1. `formalExecution`: identity, preregistration publication, five-fold split,
   capital competition, S01 translation, runtime, and timerange isolation.
2. `lockedOosAdmission`: zero-access lineage plus a frozen Locked OOS boundary,
   content hash, and one-shot unlock ledger.

A missing clean Locked OOS may block admission, but it must not erase an
otherwise valid formal Walk-forward research result.

## Frozen contracts

- Candidate: `s01_bear_idiosyncratic_selloff_recovery_4h` only.
- Universe: the immutable V16 20-instrument core universe.
- Timeframe: `4h`.
- Split: five chronological expanding folds, with purge and embargo both at
  least the 24-bar maximum holding period.
- Capital competition: the existing AlphaPilot standard portfolio risk policy,
  plus deterministic residual/recovery/liquidity/symbol ranking and duplicate
  symbol rejection.
- Costs: V16 base round-trip cost plus 1.5x and 2.0x stress; missing historical
  funding remains null and a separate conservative proxy is preregistered.
- Benchmark: the V16 frozen `same_event_fixed_12_bar_exit` benchmark is the main
  comparison; NoTrade and BTC contextual return remain diagnostics.
- Changes: one candidate, zero parameter, exit, universe, and cost changes.

## Implementation sequence

1. Add failing tests for contract hashes, five-fold boundaries, timerange/output
   isolation, S01 signal parity, and the two readiness gates.
2. Implement the preregistration builder and atomic writer.
3. Implement the pure S01 signal translation and research-only Freqtrade adapter.
4. Implement the timerange I/O guard and CLI.
5. Extend readiness reporting without opening Locked OOS.
6. Generate the preregistration, commit and publish it before any result run.
7. Rerun readiness. A missing Freqtrade runtime remains an environment blocker;
   missing clean Locked OOS remains an admission limitation.

## Safety boundary

- Locked OOS content read count stays zero.
- Formal result count stays zero in this phase.
- No Release, approval, Demo ARM, API credential, or order path is touched.
- No stop widening, adaptive parameter search, or result-driven policy change.
