# V13.27.1.12 Formal Data Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an auditable, public-data-only readiness pipeline for same-exchange derivatives evidence, historical PIT membership, and the Qlib launch gate.

**Architecture:** Extend the V13.27.1.11 derivatives-data modules with small deterministic components. Acquisition is non-destructive and budgeted; formal readiness is evaluated only from verified same-exchange historical evidence. Reports are canonical JSON/CSV with SHA-256 sidecars, while Qlib remains preflight-only.

**Tech Stack:** Python 3.11+, standard library, pandas/NumPy already locked by the repository, pytest, PowerShell, canonical JSON, LF CSV, SHA-256.

## Global Constraints

- Public market data only; no account, position, API key, Trade API, Withdraw API, Demo order, Live order, Dry-run, or automatic ARM access.
- Do not run a formal strategy campaign, unlock holdout data, create a release, or restore local simulation.
- Formal core fields for one direction must come from one exchange.
- Proxy liquidation cannot become formal liquidation evidence.
- Today's TopN cannot backfill historical PIT membership.
- Missing evidence remains missing and must never be filled with zero.
- Keep Quant main's existing report modification and Console `backups/` untouched.
- A `data_not_ready` result is valid.
