# AlphaPilot V13.4.19 - Probability Bucket Coarsening

V13.4.19 is a research-only probability bucket coverage analysis. It reads the
existing V13.4.14 probability score table and V13.4.18 pipeline diagnosis, then
generates coarsened probability tables to test whether the zero-entry result is
caused by over-fragmented buckets.

It does not modify `AlphaPilotDynamicRegimeV01.py`, does not modify the
original V13.4.14 score table, does not loosen the default strategy gate, does
not run a backtest, does not enter Dry-run, does not use API keys, does not read
accounts or positions, does not create orders, and does not auto trade.
