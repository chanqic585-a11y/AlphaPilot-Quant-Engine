# V13.4.2 Signal Audit Instrumentation

V13.4.2 adds signal audit instrumentation and filter effectiveness tracking for
AlphaPilot Volume Rebound V0.1.

This version is an evidence layer only. It does not tune parameters, does not
enter Dry-run, does not call exchange private APIs, and does not create orders.

## Inputs

Primary source report:

```text
reports/v13_4_smoke_backtest_report.json
```

The source report must be a real converted Freqtrade result:

```json
{
  "isMock": false
}
```

Local OHLCV data is read from:

```text
user_data/data/okx/futures
```

## Strategy Instrumentation

The strategy now exposes `ap_audit_` columns for local analysis:

- `ap_audit_data_ready`
- `ap_audit_base_candidate`
- `ap_audit_final_entry`
- `ap_audit_skip_reason`
- `ap_audit_failed_filters`
- `ap_audit_pass_btc_crash_filter`
- `ap_audit_pass_4h_trend_filter`
- `ap_audit_pass_rsi_filter`
- `ap_audit_pass_volume_filter`
- `ap_audit_pass_macd_filter`
- `ap_audit_pass_ema20_reclaim_filter`
- `ap_audit_pass_no_chase_filter`

Metric columns with the same prefix preserve the local values used by the
filters, such as RSI, MACD histogram, volume ratio, EMA20, Bollinger middle,
BTC three-candle return, and 4h trend context.

## Outputs

```text
reports/v13_4_2_signal_audit_report.json
reports/v13_4_2_signal_audit_summary.md
docs/filter-effectiveness-methodology.md
```

## Command

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_signal_audit.ps1
```

Direct Python entrypoint:

```powershell
python -m alphapilot.reports.generate_signal_audit_report
```

If the local Python runtime cannot read Feather files because `pyarrow` is not
installed, the generator can rerun itself in the Freqtrade Docker image and
mount the repository read/write to generate the same report files.

## Safety Boundary

V13.4.2 reads local strategy, backtest report, and OHLCV files only.

It does not:

- use real API keys
- call Trade API
- call Withdraw API
- read a real account
- read real positions
- create real orders
- auto trade
- execute Dry-run
- modify the mobile app

## Conclusion

V13.4.2 explains how V0.1 filters behave before any parameter changes. The
evidence suggests that 4h trend, RSI, and volume filters are the largest primary
blocks in the current smoke sample. This prepares V13.4.3 strategy V0.2
candidate design, but V13.4.2 itself does not change strategy parameters.
