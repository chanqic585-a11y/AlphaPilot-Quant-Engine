# Mainstream Coin Research Scope

V13.4.31 narrows the research universe.

## Included

```text
BTC/USDT:USDT
ETH/USDT:USDT
SOL/USDT:USDT
```

## Primary Timeframes

```text
4h
1d
```

## Optional Informative Timeframe

```text
1h
```

1h can be used for entry refinement later, but it is not the main signal loop.

## Excluded From Mainline

- Top30 broad expansion.
- Full-market scanning.
- New listings.
- Low-liquidity altcoins.
- High-frequency 15m/1h loops.

These can be used as future benchmarks or diagnostics, but not as the next mainline.

## Rationale

The V13.4.29 short-only research strategy produced too many trades and a near-total expanded loss. V13.4.31 lowers frequency and scope before any new strategy implementation.
