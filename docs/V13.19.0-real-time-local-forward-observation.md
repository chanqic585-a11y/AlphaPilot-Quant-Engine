# AlphaPilot V13.19.0 - Real-Time Local Forward Observation

## Purpose

V13.19 creates the first evidence class that advances only when a new public
market candle is actually observed. It is not a historical replay, not an
exchange Demo account, and not an order executor.

## Forward Lifecycle

```text
immutable StrategyCandidate
  -> candidate-bound historical path replay
  -> immutable ForwardRelease
  -> confirmed OKX public candle
  -> frozen factor policy at candle close
  -> next completed candle open virtual fill
  -> 1R stop / 2R target observation
  -> immutable ForwardEvents and Outcome Ledger row
```

Only formal candidate-bound replay may create a ForwardRelease. V13.18 engine
probe results are rejected by this gate.

## Event-Sourced State

Registry migration 3 adds:

- `ForwardReleases`: frozen strategy, data, model/rule, risk, and replay lineage;
- `ForwardSessions`: one stable 1000 USDT virtual test account per release/account;
- `ForwardEvents`: append-only signals, rejections, marks, closes, gaps,
  collection failures, and checkpoints.

The latest checkpoint restores cash, equity, fees, drawdown, pending next-bar
signals, open virtual positions, and last observed candle timestamps. Replaying
the same completed candle is rejected idempotently.

## Time Integrity

Forward evidence cannot be accelerated. If the process is stopped, the next
observed candle is compared with the last checkpoint. Missing intervals become
a `collection_gap` event and are not replayed or backfilled as forward data.
Only exchange-confirmed candles (`confirm=1`) are accepted.

## Current Result

The real registry contains no formal StrategyCandidate. Therefore V13.19 has
zero ForwardReleases, sessions, and forward outcomes. Its runtime report is
`blocked_no_eligible_forward_release`. This is the correct fail-closed state,
not an implementation failure.

## Safety Boundary

- public market data only;
- 1000 USDT virtual capital only;
- no credentials or account state;
- no Trade API or Withdraw API;
- no exchange order creation or cancellation;
- no Demo or Live execution;
- no synthetic downtime samples;
- no profitability claim.
