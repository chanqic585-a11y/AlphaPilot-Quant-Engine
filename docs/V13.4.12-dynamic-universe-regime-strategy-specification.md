# AlphaPilot V13.4.12 - Dynamic Universe and Regime Strategy Specification

V13.4.12 defines the new AlphaPilot strategy mainline:

```text
AlphaPilot Dynamic Regime Strategy V0.1
```

中文名称：

```text
AlphaPilot 动态市场状态策略 V0.1
```

This version is specification-only. It does not implement strategy code, does
not download data, does not run backtests, does not enter Dry-run, and does not
create real orders.

## Why The Mainline Changes

Earlier strategies exposed the same core weakness:

```text
fixed Top30 universe
single rule set across too many coins
high sensitivity to slippage and execution cost
weak generalization from small smoke samples
insufficient live execution feasibility evidence
```

The new mainline changes the order of research:

```text
Universe -> Regime -> Module -> Probability -> Liquidity -> Risk -> Backtest / Shadow
```

## Architecture

```text
public exchange data
```

## V13.4.12 Scope

V13.4.12 defines:

- Dynamic Universe
- Historical Dynamic Universe Snapshots
- Market Regime Router
- Trend Continuation Module
- Mean Reversion Module
- Probability Score
- Backtest plan
- Roadmap to implementation

V13.4.12 does not implement:

- Freqtrade strategy code
- machine learning
- news data
- breakout module
- real-time orderbook depth collection
- Dry-run
- live trading
- automatic trading
