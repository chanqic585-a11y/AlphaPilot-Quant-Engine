# AlphaPilot V13.17.0 - Point-in-Time FactorRun and Backtest

## Purpose

V13.17 converts one immutable DataSnapshot into auditable factor, label,
walk-forward, model, and strategy-gate evidence. It does not bypass the V13.16
provenance blocker and does not create an execution release.

## Factor Matrix

The 4-hour BTC/ETH/SOL smoke matrix contains ten restricted DSL expressions:

- one- and six-bar returns;
- 12-bar realized volatility;
- 20-bar volume ratio;
- close distance from EMA20 and EMA50;
- RSI14;
- MACD histogram 12/26/9;
- Bollinger normalized position;
- ATR14 divided by close.

Every expression is parsed, canonicalized, validated against approved fields
and operators, registered as a FactorDefinition, and materialized as a
FactorRun tied to the DataSnapshot, code commit, configuration hash, result
path, and result SHA-256. A metadata manifest binds all FactorRuns to the same
Parquet matrix.

## Label Contract

```text
decision: completed bar t
entry: next bar open
stop: 1R
target: 2R
maximum holding period: 12 bars
same-bar target and stop: stop first
fees: 5 bps per side
slippage: 2 bps per side
```

Long and short labels are separate. A one-bar-delayed execution path is also
materialized for latency stress. Incomplete future paths are unavailable, not
silently filled.

## Evaluation Contract

- Final 20% of unique timestamps is locked before model evaluation.
- Development data uses at least three expanding purged walk-forward folds.
- Embargo covers the full maximum holding period.
- Logistic regression and gradient-boosted stumps use registered FactorRuns.
- The selected model is the lowest development-OOS Brier score, with a stable
  model-name tie break; no parameter search uses the locked set.
- The locked set is accessed once after model selection.
- Strategy metrics use a fixed probability threshold of 0.55.
- Cost stress includes baseline, 2x, 3x, one-bar delay, and one extreme gap.
- Pair and month stability plus Benjamini-Hochberg decisions are recorded.

## Evidence Boundary

The current composite DataSnapshot is hash-valid and continuous, but its local
base has unknown authoritative provenance. FactorRuns and research models may
therefore be recorded as engineering smoke evidence, while formal promotion
stays false. StrategyCandidate creation requires both the performance gate and
formal snapshot provenance; no missing evidence is invented.
