# AlphaPilot V13.7.4 - Strategy Artifact Center

V13.7.4 adds a read-only Strategy Artifact Center for the Quant Engine, Control Console, and mobile console.

## Purpose

The artifact center turns scattered local research reports into a single indexed file:

```text
reports/strategy_artifact_index.json
```

This lets the console answer:

- Which strategy artifacts exist?
- Which reports produced them?
- Which artifacts have standard metrics?
- Which artifacts are only research evidence?
- Which artifacts might be ready for local paper observation?

## Data Source

The generator only reads local JSON files under:

```text
reports/
```

It does not download data, run backtests, call exchanges, or execute strategies.

## Readiness Tiers

The index uses conservative routing labels:

- `paper_observation_ready`: enough standard metrics for local paper observation review.
- `research_watchlist`: useful research context, but not ready for paper observation routing.
- `needs_review`: missing standard metrics or requires manual review.
- `archived_or_failed`: weak, failed, or negative research artifact.
- `blocked_by_safety_review`: safety fields indicate the artifact must not be surfaced as runnable.

These labels are not trading approval.

## Safety Boundary

V13.7.4 keeps the same execution boundary:

- No Trade API.
- No Withdraw API.
- No API Key storage.
- No account reads.
- No position reads.
- No order creation.
- No dry-run execution.
- No live trading.
- No auto trading.

The artifact index is a research-routing file only.
