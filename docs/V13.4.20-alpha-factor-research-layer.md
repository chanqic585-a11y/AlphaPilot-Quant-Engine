# AlphaPilot V13.4.20 Alpha Factor Research Layer

V13.4.20 replaces the previously considered probability gate candidate wiring
step with a design-only Alpha Factor Research Layer and Benchmark Strategy
Suite.

The reason is simple: V13.4.19 found research buckets after coarsening, but the
coarse profit factor values are bucket-level approximations. They should not be
wired directly into strategy entry logic without raw sample factor research.

中文说明：V13.4.20 只设计 AlphaPilot 自己的因子研究层和基准策略组，不写交易策略，不回测，不进入 Dry-run，不接真实 API Key。

## Scope

V13.4.20 defines:

- FactorDataPanel schema
- factor operator subset
- manual factor library V01
- factor evaluation metric schema
- benchmark strategy suite
- strategy research factory
- integration boundary with Dynamic Universe and Regime Router

## Open Source Reference Boundary

The design borrows ideas from:

- alpha101 style factor research workflow
- CryptoAgentPro-style regime and benchmark architecture

It does not copy external source code and does not import either project as a
dependency.

## Safety Boundary

V13.4.20 does not:

- implement a Freqtrade trading strategy
- run a backtest
- enter Dry-run
- read real accounts or positions
- create real orders
- connect Trade API or Withdraw API
- save real API keys
- auto trade
