# V13.5.3 Local Paper Sandbox Ledger

V13.5.3 starts the first local paper sandbox ledger for the V13.5.2 approved
candidate.

This is not exchange Dry-run and not live trading.

## Inputs

```text
reports/v13_5_2_forward_confirmation_report.json
reports/v13_5_2_forward_confirmation_signal_log.json
```

## Approved Candidate

```text
candidateId: v13_5_1_1h_short_reversal_bull_relative_return
condition: short_reversal_candidate + BTC bull regime + relative_return_6 between -1% and 1%
timeframe: 1h
```

## Local Simulation Rules

```text
initialEquity: 10000
riskPerSignalPct: 1%
maxConcurrentPositions: 8
maxNotionalPerSignalPct: 35%
stopLossPct: inherited from V13.5.2 barrier config
```

Position sizing is local research accounting:

```text
riskAmount = equity * riskPerSignalPct
notional = min(riskAmount / stopLossPct, equity * maxNotionalPerSignalPct)
pnl = notional * netReturnPct
```

The ledger consumes historical signal rows that already include simulated
entry/exit outcomes. It does not place orders and does not connect to an
exchange.

## Safety Boundary

- Local simulated capital only.
- No Trade API.
- No Withdraw API.
- No API key storage.
- No real account reads.
- No real position reads.
- No real orders.
- No automatic trading.
- Exchange Dry-run remains disabled.
