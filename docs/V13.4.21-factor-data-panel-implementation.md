# V13.4.21 Factor Data Panel Implementation

V13.4.21 implements the first local FactorDataPanel builder for the AlphaPilot
Alpha Factor Research Layer.

This version is research-only:

- no backtest execution
- no Dry-run
- no live trading
- no API key
- no Trade API
- no Withdraw API
- no account or position reads
- no real order creation
- no automatic trading

## What Changed

Implemented modules:

```text
alphapilot/factors/ohlcv_loader.py
alphapilot/factors/factor_data_panel.py
alphapilot/factors/compute_manual_factors.py
alphapilot/factors/build_factor_data_panel.py
scripts/build_factor_panel.ps1
```

Updated modules:

```text
alphapilot/factors/factor_schema.py
alphapilot/factors/manual_factor_library.py
alphapilot/factors/factor_operator_spec.py
```

## Inputs

The builder reads local public Freqtrade OHLCV files under:

```text
user_data/data/okx/futures
```

Supported local file formats:

```text
.feather
.parquet
.json
.json.gz
```

The default build uses:

```text
timerange = 20260101-
timeframe = 1h
pairs = auto-discovered local futures pairs
```

## Outputs

```text
reports/v13_4_21_factor_panel_report.json
reports/v13_4_21_factor_panel_summary.md
reports/v13_4_21_factor_panel_sample.json
reports/v13_4_21_manual_factor_library_report.json
```

Only the sample panel is committed. A full panel can be generated later into a
generated report directory if needed, but should not become a routine git
artifact.

## Run

```powershell
python -m alphapilot.factors.build_factor_data_panel
```

or:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_factor_panel.ps1
```

## Result

The local V13.4.21 build generated a successful research panel from local
public OKX futures OHLCV:

```text
rowsGenerated = 124111
loadedPairs = 28
```

## Boundary

FactorDataPanel rows and manual factor outputs are research features. They are
not strategy entries, trade signals, trading advice, orders, or approval for
Dry-run/live trading.
