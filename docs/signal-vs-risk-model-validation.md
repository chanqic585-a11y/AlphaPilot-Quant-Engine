# Signal vs Risk Model Validation

策略信号和账户风险模型必须分层验证。仓位缩小可以降低回撤，但不能把负期望或不稳定信号变成有效 alpha。

## 信号层

信号层基于非锁定的开发、Walk-forward 和 holdout 逐笔净 R，检查：

- PF 不低于 1.10；
- 平均净 R 不低于 0.05；
- Bootstrap 中平均净 R 为正的概率不低于 90%；
- 正平均 R 的 Walk-forward 窗口比例不低于 60%；
- 多重试验使用 Benjamini-Hochberg 校正。

## 成本与稳定性

1.0x、1.5x、2.0x 成本全部公开。1.5x 是硬压力门槛，2.0x 是观察层。稳定性还要求至少两个正 Walk-forward 窗口，单一币种和单一月份的正贡献占比均不高于 35%。

## 风险模型

- 模型零：信号归一化参考，不参与账户验收。
- 模型一：单笔账户风险 0.25%，是唯一主验收模型。
- 模型二：标准固定比例，仅敏感性分析。
- 模型三：相关性约束，仅敏感性分析。

模型二或模型三表现更好时，不能挽救模型一或信号层失败。主模型要求历史最大回撤不高于 15%，Monte Carlo 95% 最大回撤不高于 25%。

## 退出与 R

`2R` 是相对单笔初始风险的收益目标，不是本金翻倍。研究可以比较固定 2R 与预注册的 runner/保护退出，但不能在看到锁定结果后选择最佳退出路径。任何新退出逻辑都必须创建新研究版本重新走完整流程。
