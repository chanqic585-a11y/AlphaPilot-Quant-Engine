# AlphaPilot V13.27.0 - Unified Workflow Foundation

V13.27.0 adds the immutable workflow foundation for the approved strategy
lifecycle:

```text
Strategy backtest -> Local real-time forward -> OKX Demo -> Live
```

This release provides orchestration state and auditability only. It does not
launch a backtest worker, submit an OKX Demo order, or enable Live execution.

## Registry migration v6

The evolution registry now includes:

- `StrategyVersions`: immutable strategy logic and parameter versions;
- `GateProfiles`: immutable stage-gate definitions;
- `WorkflowRuns`: restart-safe stage attempts with idempotency keys;
- `StageEvents`: append-only workflow transition and checkpoint history;
- `FailureDiagnoses`: structured failure category, metrics, suggestions, and
  retry disposition.

The migration only uses `CREATE TABLE IF NOT EXISTS` and
`CREATE INDEX IF NOT EXISTS`. Existing registry tables and records are not
deleted or rebuilt.

## Fail-closed workflow rules

- One strategy version can have only one active run for a stage.
- Users may queue or cancel work, but cannot mark a result passed or failed.
- Passed, failed, and blocked results require a worker, system, or recovery
  actor.
- Operational failures may retry the same immutable version.
- Strategy-performance failures require a changed challenger version.
- Every challenger starts again at backtesting; prior passing evidence is not
  inherited.
- Checkpoints and events remain available after reconnecting to the registry.
- The projection places each strategy version on exactly one current page.

## Current public API

The narrow API is exported from:

```text
alphapilot/evolution/workflow/__init__.py
```

Domain implementation is split across `types.py`, `states.py`,
`repository.py`, `service.py`, and `projection.py` so later workers and console
adapters do not need to depend on registry internals.

## Safety boundary

V13.27.0 adds no exchange adapter, private API request, credential storage,
order creation, automatic promotion, or automatic trading. Withdraw remains
unsupported. The workflow projection is read-only and explicitly reports this
boundary.

The next release, V13.27.1, will connect real backtest work to these records
and expose concise strategy-page lanes without changing this immutable state
contract.
