# AlphaPilot V13.27.5 - Cancelled Attempt Resume

V13.27.5 fixes workflow controls without changing strategy definitions,
backtest evidence gates, or execution permissions.

## Behavior

- A queued backtest uses pause, not terminal cancel.
- A paused run can return to the durable serial queue.
- A cancelled run can create one idempotent successor attempt from its saved
  checkpoint. The cancelled attempt and its audit events remain unchanged.
- One process-wide lock allows only one serial backtest batch to execute.
- The active batch drains backtests queued while it is running.
- A pause during official OKX history collection leaves the current phase
  incomplete. Resume re-enters collection from the saved partition checkpoint
  instead of validating a paused partial result.
- One-click launches use the same process-wide batch lock, preventing repeated
  clicks from creating competing public-data download workers.

## Official data duration

Formal collection is intentionally much larger than a smoke backtest. The
strategy contract requests point-in-time Top50 history from 2020 onward. OKX
returns at most 100 history candles per page, so a single 5-minute
symbol/timeframe partition can require roughly 6,000 to 7,000 public requests.
The visible partition count advances only after that complete partition is
validated and written. Network latency and exchange rate limiting add to this
time; progress remaining unchanged for one partition does not by itself mean
that the worker is stuck.

Formal evidence remains unchanged. A strategy still requires point-in-time
data, costs, walk-forward and locked OOS evidence, with targetR >= 2.
No API key, exchange order, Live permission, or Withdraw capability is added.
