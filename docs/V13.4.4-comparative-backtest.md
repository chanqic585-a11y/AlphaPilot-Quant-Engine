# V13.4.4 V0.1 vs V0.2 Comparative Backtest

V13.4.4 compares the unchanged V0.1 baseline with five V0.2 candidate
strategies under the same smoke scope.

This version runs local Freqtrade backtesting only. It does not enter Dry-run,
does not approve live trading, does not use real API keys, and does not create
orders.

## Scope

```text
Pairs: BTC/USDT:USDT, ETH/USDT:USDT, SOL/USDT:USDT
Timerange: 20260401-
Timeframe: 15m
Fee: 0.0005
Slippage applied by engine: false
```

## Strategies

Baseline:

```text
AlphaPilotVolumeReboundV01
```

Candidate strategies:

```text
AlphaPilotVolumeReboundV02ATrendStrict
AlphaPilotVolumeReboundV02BVolumeQuality
AlphaPilotVolumeReboundV02CExitCleanup
AlphaPilotVolumeReboundV02DEarlyFailureExit
AlphaPilotVolumeReboundV02EPairRiskWatchlist
```

V0.1 was not modified.

## Result Summary

```text
Baseline V0.1: -15.542% return, 24.4939% drawdown, 0.8107 profit factor
V0.2A Trend Strict: -11.6607% return, 21.0664% drawdown, 0.8251 profit factor
V0.2B Volume Quality: -4.0845% return, 11.4841% drawdown, 0.9104 profit factor
V0.2C Exit Cleanup: -6.1609% return, 17.8594% drawdown, 0.9319 profit factor
V0.2D Early Failure Exit: -15.6258% return, 24.3002% drawdown, 0.7979 profit factor
V0.2E Pair Risk Watchlist: -10.3361% return, 17.93% drawdown, 0.8406 profit factor
```

V0.2A, V0.2B, V0.2C, and V0.2E passed the first relative comparison gate
against V0.1. V0.2D did not pass.

However, every candidate still has negative total return in this smoke sample.
Therefore, V13.4.4 does not approve Dry-run.

## Interpretation

- V0.2B has the best total return and drawdown in this smoke comparison.
- V0.2C has the best profit factor and win rate, but stop-loss loss increased.
- V0.2E reduces SOL exposure and improves drawdown versus baseline.
- V0.2D early time stop worsened total return and profit factor.

## Safety Boundary

V13.4.4 does not:

- modify V0.1 baseline strategy logic
- modify default config strategy
- enter Dry-run
- approve live trading
- use real API keys
- call Trade API
- call Withdraw API
- read real accounts
- read real positions
- create real orders
- auto trade
- modify the mobile app
