# V13.5.2 Forward Confirmation and Local Paper Sandbox

V13.5.2 replays the deterministic candidates found in V13.5.1 as fixed
research rules and evaluates their final holdout segment.

This version is still research-only:

- No Trade API.
- No Withdraw API.
- No API key storage.
- No real account reads.
- No real position reads.
- No real orders.
- No automatic trading.
- No Freqtrade exchange Dry-run approval.

## Local Paper Sandbox Definition

`localPaperSandboxApproved=true` means AlphaPilot can start local simulated
observation for the approved candidate. It does not mean exchange Dry-run and
does not connect to any private exchange endpoint.

The V13.5.2 gate is intentionally narrower than live or exchange-dry-run gates:

```text
confirmation trades >= 50
confirmation win rate >= 55%
confirmation reward/risk >= 1.8
confirmation profit factor >= 1.35
confirmation max drawdown <= 20%
confirmation return > 0
```
