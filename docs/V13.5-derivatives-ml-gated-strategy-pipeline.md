# V13.5 - Derivatives ML-Gated Strategy Pipeline

V13.5 moves AlphaPilot away from repeated OHLCV-only rule tuning and into a
derivatives-aware, probability-gated strategy research pipeline.

This version is still research-only:

- no Dry-run approval
- no live trading approval
- no API key storage
- no Trade API
- no Withdraw API
- no account reads
- no position reads
- no order creation
- no auto trading

## Why V13.5 Exists

V13.4 through V13.4.35 repeatedly showed that plain OHLCV technical rules did
not clear the research gate. The new target is stricter and more practical:

- win rate above 55%
- reward/risk close to 2:1
- profit factor above 1.35
- at least 100 trades
- max drawdown below 20%
- positive after estimated fees and slippage
- walk-forward validation before any paper testing

## Pipeline

1. Build a local public derivatives feature panel.
2. Label candidate events with a triple-barrier outcome.
3. Apply a walk-forward probability gate.
4. Mine deterministic candidate rules for explainability.
5. Reject candidates that do not clear the hard gate.
6. Only approved candidates can move to shadow or paper testing.

## Data Sources

V13.5 reads local Freqtrade public data only:

- futures OHLCV
- mark price, when present
- funding rate, when present

Open interest is recorded as unavailable when no local public historical file is
present. V13.5 does not fabricate open interest.
