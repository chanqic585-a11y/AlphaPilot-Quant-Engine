# AlphaPilot V13.5.15 - Multi-Exchange Historical Data Coverage

V13.5.15 expands the research pipeline from a single-exchange historical view toward an auditable multi-exchange public-data map.

This version does not modify strategy parameters. It does not run Dry-run, connect to private exchange endpoints, create orders, or approve live trading.

## What Changed

- Added a local public OHLCV coverage reporter.
- Added coverage scanning for OKX, Binance, and Bybit.
- Added BTC/ETH/SOL core multi-exchange coverage checks.
- Added a report that records which Top 100 files are actually present locally.
- Recorded that large Top 100 historical downloads can be partial and must be reported honestly.

## Commands

Preview:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_15_multi_exchange_data_coverage.ps1
```

Generate reports:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_v13_5_15_multi_exchange_data_coverage.ps1 -Run
```

Outputs:

```text
reports/v13_5_15_multi_exchange_data_coverage_report.json
reports/v13_5_15_multi_exchange_data_coverage_summary.md
```

## Interpretation

The report is a data readiness map. It answers:

- Which exchange/pair/timeframe files exist locally?
- How many rows each file has?
- What first and last timestamps are available?
- Whether BTC/ETH/SOL core data is available across OKX, Binance, and Bybit?
- Whether a full Top 100 multi-exchange validation is ready?

The report does not answer:

- Whether a strategy is profitable.
- Whether a symbol should be traded.
- Whether Dry-run should start.
- Whether live trading should start.

## Safety Boundary

- No Trade API.
- No Withdraw API.
- No API key storage.
- No real account reads.
- No real position reads.
- No order creation.
- No automatic trading.
- No exchange Dry-run approval.
- No live-trading approval.

## Next Step

The next step is to build an exchange-aware feature panel and rerun a core BTC/ETH/SOL replay across OKX, Binance, and Bybit. Only after that should expanded Top 100 downloads be retried in smaller resumable batches.
