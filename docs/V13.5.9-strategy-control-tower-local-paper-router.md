# V13.5.9 Strategy Control Tower and Local Paper Router

V13.5.9 coordinates existing AlphaPilot research outputs into a conservative
strategy state machine and local paper router.

It does not create exchange orders, connect to exchanges, store API keys, enter
exchange Dry-run, or auto trade.

- `reports/v13_5_7_external_alpha_overlay_report.json`
- `reports/v13_5_8_adaptive_ml_factor_report.json`

- `reports/v13_5_4_local_paper_monitoring_report.json`

## Outputs

## State Machine

The control tower uses these states:

```text
research_candidate
local_paper_watch
paper_trial
dry_run_review
rejected
promoted
```

V13.5.9 keeps V13.5.7 as the only active local paper watch strategy and keeps
V13.5.8 adaptive ML as observer-only.

## Router Intents

Router intents are local research records:

- they are not orders
- they do not call exchange APIs
- they do not require API keys
- they do not read accounts or positions
- they do not trigger emergency close
- they do not run testnet execution
- they do not auto trade

## External Reference Use

`yydhYYDH/alpha101` is recorded as a factor-research reference for panels,
expression grammar, factor search, and IC-style evaluation.

`ryckli/CryptoAgentPro.beta` is recorded as a future live-trading boundary
reference for paper/testnet separation, risk gateway, human confirmation,
emergency controls, and execution-related architecture.

Neither project is imported as a dependency. No source code or large text is
copied.

## Safety Boundary

V13.5.9 remains local paper only:

- no Trade API
- no Withdraw API
- no API key storage
- no real account reads
- no real position reads
- no real orders
- no emergency close implementation
- no testnet execution implementation
- no automatic trading
