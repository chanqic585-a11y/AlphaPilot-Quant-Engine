# AlphaPilot V13.27.4 - Workflow Recovery and Demo Release

V13.27.4 fixes workflow control without changing strategy definitions or the
formal evidence standard.

## Worker Recovery

- Official history collection checks the durable workflow state before every
  public OKX history page.
- A pause stops the active worker without deleting downloaded partitions or
  checkpoints.
- Resume waits for the old run-scoped lock before returning the workflow to the
  queue.
- Selected backtests are all queued first and then processed by one serial
  worker in caller order.
- Startup recovery accepts interrupted `queued` and `running` runs without
  launching competing workers.

## Local Forward Identity

A formal pass still creates a local-forward release and runs the first public
completed-candle cycle automatically. The resulting workflow keeps the
immutable `strategyCandidateId` in success and failure evidence so downstream
controls do not match by strategy name.

## Safety Boundary

- Formal backtests remain historical point-in-time dynamic Top50 tests.
- `targetR >= 2` remains fixed.
- Backtest and local forward use public data only.
- Local forward creates no exchange order.
- A controlled override may create only an OKX Demo release.
- Pre-Demo direct live promotion remains forbidden.
- Withdraw and raw credential persistence remain absent.
